## The Basics

Inorder traversal follows the rule: **Left -> Root -> Right**. Similar to Preorder traversal, the algorithm relies entirely on recursion. The philosophy remains the same: do not overcomplicate binary trees. Write the code in the exact sequence the traversal dictates.

## The Code Logic (Recursive)

1. **Base Case:** If the current `node` is `null`, `return` (do nothing).
    
2. **Visit Left:** Make a recursive call to `inorder(node.left)`.
    
3. **Process Root:** Print (or process) the data of the current `node`.
    
4. **Visit Right:** Make a recursive call to `inorder(node.right)`.
    

## Dry Run Visualization

When dry running this recursive function, you track three steps for every node: **Left**, **Print**, and **Right**.

- You start at the main root. The first instruction is to go Left.
    
- The function continues plunging down the left side of the tree until it hits a `null` (meaning a leaf node has no left child).
    
- Hitting `null` triggers the base case and returns the function back to the previous node.
    
- Once the "Left" call is completely resolved for a node, it moves to the next instruction: **Print** that node's value.
    
- After printing, it moves to the "Right" instruction, applying the exact same recursive logic to the right subtree.
    
- Only when a node has successfully resolved its Left child, Printed its own value, and resolved its Right child is it popped completely off the recursive call stack.
    

## Key Takeaway

Recursion effectively handles the "go down, come back up, go down the other side" movement required for traversing subtrees. The entire trick is trusting the recursive call stack to backtrack correctly.

## Active Recall

**Q1: What is the exact sequence for an Inorder traversal?** **Answer:** Left -> Root -> Right.

**Q2: In the recursive implementation, what triggers the function to finally print a node's value?** **Answer:** A node's value is printed immediately after its `inorder(node.left)` recursive call has completely finished and returned.

**Q3: What is the base case for the recursive inorder function?** **Answer:** If the node is `null`, the function simply returns.

**Q4: If a node is a leaf (it has no left or right children), what happens during its traversal?** **Answer:** Its left call returns immediately (since it's null), it prints its own value, and then its right call returns immediately (since it's null). The node is then popped off the stack.
