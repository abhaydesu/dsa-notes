## The Basics

Preorder traversal follows the rule: **Root -> Left -> Right**. The implementation in C++ and Java is almost identical and relies heavily on recursion. The core philosophy of writing tree algorithms is to keep it simple: just write the code in the exact sequence you want to execute the traversal.

## The Code Logic (Recursive)

1. **Base Case:** If the current `node` is `null`, `return` (do nothing).
    
2. **Process Root:** Print (or process) the data of the current `node`.
    
3. **Visit Left:** Make a recursive call to `preorder(node.left)`.
    
4. **Visit Right:** Make a recursive call to `preorder(node.right)`.
    

## Dry Run Visualization

When dry running recursive tree code, it is helpful to track three steps for every single node: **Print**, **Left**, and **Right**.

- The recursion starts at the main root. It immediately prints the root.
    
- It then moves to the left child and pauses the current function call.
    
- It treats that left child as a brand new tree, prints it, and moves to _its_ left child.
    
- If it hits a `null` node (a leaf's child), the function returns, resolving the paused "Left" step.
    
- It then moves to the "Right" step. Once Print, Left, and Right are all resolved for a specific node, that function call is completely popped off the stack, and the program backtracks to the previous node.
    

## Complexity

- **Time Complexity:** **O(N)**, where N is the number of nodes in the tree. You are visiting every single node exactly once.
    
- **Space/Auxiliary Complexity:** **O(N)** in the worst case. This happens when the tree is a completely unbalanced "skewed tree" (e.g., every node only has a left child), meaning the recursive call stack goes N levels deep. For a balanced tree, the space complexity would be **O(H)**, where H is the height of the tree.
    

## Active Recall

**Q1: What is the sequence for a Preorder traversal?** **Answer:** Root -> Left -> Right.

**Q2: In the recursive code, what is the base condition that stops the recursion?** **Answer:** If the current node is `null`, the function returns.

**Q3: Why is the time complexity of the Preorder traversal O(N)?** **Answer:** Because the traversal visits every single node in the binary tree exactly once.

**Q4: What is the worst-case space complexity and what type of tree causes it?** **Answer:** The worst-case auxiliary space complexity is O(N). This occurs in a skewed tree, where the recursive call stack goes all the way down to N nodes before resolving.
