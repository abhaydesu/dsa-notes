## The Basics

The **Maximum Depth** (or height) of a binary tree is the number of nodes along the longest path from the root node down to the farthest leaf node.

- There are two main ways to find this: **Level Order Traversal (BFS)** and **Recursive Traversal (DFS)**.
    
- **Recursive Traversal** is the standard and preferred approach because it requires less code and relies purely on a simple mathematical recurrence.
    

## The Core Logic (Recursive Approach)

The height of any given tree (or subtree) can be broken down logically: **Height = 1 + Maximum(Height of Left Subtree, Height of Right Subtree)**

- The `1` accounts for the current node you are standing on.
    
- You then look at both the left and right branches, see which one is longer, and add that longest branch's length to your `1`.
    

## The Algorithm Steps

1. **Base Case:** If the current `node` is `null`, it contributes nothing to the height. Return `0`.
    
2. **Left Check:** Recursively calculate the height of the left subtree (`left_height = findHeight(node.left)`).
    
3. **Right Check:** Recursively calculate the height of the right subtree (`right_height = findHeight(node.right)`).
    
4. **Calculate & Return:** Return `1 + max(left_height, right_height)`.
    

## Complexity Analysis

- **Time Complexity:** **O(N)**. To find the true maximum depth, you absolutely must visit every single node in the tree to check its path. You cannot do this in less than O(N) time.
    
- **Space Complexity:** **O(H)**, where H is the height of the tree. This is due to the recursion stack.
    
    - **Worst Case (Recursive):** **O(N)** space if the tree is a completely unbalanced "skewed tree" (e.g., a straight line of left children).
        
    - **Worst Case (Level Order):** **O(N)** space if the tree is a "complete binary tree", meaning the queue at the bottom level will hold roughly half of all the nodes in the tree at the same time.
        

## Active Recall

**Q1: What is the primary mathematical formula used to recursively find the maximum depth of a binary tree?** **Answer:** Height = 1 + max(Left Subtree Height, Right Subtree Height).

**Q2: In the recursive function, what should be returned if the current node is `null`?** **Answer:** `0`. A null node has no height.

**Q3: Why is the time complexity strictly O(N) for finding the maximum depth?** **Answer:** Because it is impossible to guarantee you have found the longest path without visiting every single node in the tree at least once.

**Q4: Under what condition does the recursive approach have a worst-case space complexity of O(N)?** **Answer:** When the tree is a "skewed tree" (essentially a linked list), causing the recursion stack to go N levels deep.

**Q5: What is the main disadvantage of using Level Order Traversal (BFS) to find the height compared to recursion?** **Answer:** Level Order requires maintaining a Queue data structure. For a completely balanced tree, the bottom level will hold a massive number of nodes, making the queue memory-heavy.
