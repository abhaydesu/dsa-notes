## The Basics

To solve any computational problem involving trees, you must know how to visit every node. This process is called traversal. There are two primary techniques to traverse a binary tree:

1. **Depth-First Search (DFS):** Explores vertically, going deep into subtrees before moving across.
    
2. **Breadth-First Search (BFS):** Explores horizontally, moving across the tree level by level.
    

## Depth-First Search (DFS)

DFS is divided into three types. The easiest way to memorize them is by looking at the position of the **Root** in the name.

- **Preorder Traversal** (Root is _pre_ / at the start)
    
    - Sequence: **Root -> Left -> Right**
        
- **Inorder Traversal** (Root is _in_ between)
    
    - Sequence: **Left -> Root -> Right**
        
- **Postorder Traversal** (Root is _post_ / at the end)
    
    - Sequence: **Left -> Right -> Root**
        

**How to trace DFS manually:** You must apply the traversal rule recursively to every subtree. For example, if you are doing Inorder (Left -> Root -> Right):

1. Go to the extreme Left subtree and apply the exact same Left -> Root -> Right logic.
    
2. Once the entire left side is done, visit the Root of the main tree.
    
3. Finally, go to the Right subtree and apply the Left -> Root -> Right logic to that entire branch.
    

_Study Tip:_ To truly master DFS traversals and build visual confidence, draw 10 random binary trees on paper and manually write out the Preorder, Inorder, and Postorder sequences for each.

## Breadth-First Search (BFS)

- **How it works:** BFS explores the tree strictly **level-wise**.
    
- **Execution:** You start at the very top level (the main root), read the nodes from left to right, and then move down to the exact next level, reading left to right again.
    
- **Comparison:** Because it simply reads level by level, tracing BFS manually is usually much easier and more intuitive than tracing DFS.
    

## Active Recall

**Q1: What are the two primary techniques used to traverse a binary tree?** **Answer:** Breadth-First Search (BFS) and Depth-First Search (DFS).

**Q2: What dictates the naming convention for the three DFS traversals?** **Answer:** The position of the Root node. Preorder puts the root first, Inorder puts it in the middle, and Postorder puts it last.

**Q3: What is the exact sequence for a Postorder traversal?** **Answer:** Left -> Right -> Root.

**Q4: If a traversal explores the tree level by level from left to right, which search technique is being used?** **Answer:** Breadth-First Search (BFS).

**Q5: How do you handle a subtree when executing an Inorder traversal?** **Answer:** You apply the exact same formula (Left -> Root -> Right) recursively to that specific subtree before moving on to the next step of the main tree.
