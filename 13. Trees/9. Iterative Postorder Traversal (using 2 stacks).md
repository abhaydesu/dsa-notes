## The Basics

Postorder traversal sequence is: **Left -> Right -> Root**. Doing this iteratively (without recursion) can be tricky. One of the simplest iterative approaches uses **two Stacks** to reverse-engineer the required sequence.

## The Core Concept

If you think about the exact opposite of Postorder (Root -> Right -> Left), it looks a lot like Preorder (Root -> Left -> Right), just with the children swapped. By using two stacks, we can generate a Root -> Right -> Left sequence in `Stack 1`, and push every processed node into `Stack 2`. Because a stack reverses the order of elements when you pop them out, popping everything out of `Stack 2` at the end flips "Root -> Right -> Left" into the correct "**Left -> Right -> Root**" sequence.

## The Algorithm

1. **Initialize:** Create `Stack 1` and `Stack 2`.
    
2. **Start:** Push the main `root` of the tree into `Stack 1`.
    
3. **Iterate:** Create a `while` loop that runs as long as `Stack 1` is not empty:
    
    - Pop the top node from `Stack 1`.
        
    - Immediately push this popped node into `Stack 2`.
        
    - Check if the popped node has a **left** child. If yes, push it into `Stack 1`.
        
    - Check if the popped node has a **right** child. If yes, push it into `Stack 1`.
        
4. **Finish:** Once `Stack 1` is completely empty, the loop ends.
    
5. **Extract Answer:** Pop every node out of `Stack 2` one by one. The order they come out is your perfect Postorder Traversal.
    

_Note: In step 3, you must push the left child into Stack 1 before the right child. This ensures the right child is popped first in the next iteration._

## Complexity

- **Time Complexity:** **O(N)**. You visit every node, push it to Stack 1, pop it, push it to Stack 2, and pop it again. It scales linearly with the number of nodes.
    
- **Space Complexity:** **O(N) + O(N) = O(N)**. You are using two stacks, and in the worst-case, `Stack 2` will store every single node in the tree (N nodes) before you start popping them out.
    

## Active Recall

**Q1: What is the sequence for a Postorder Traversal?** 

**Answer:** Left -> Right -> Root.

**Q2: In the 2-Stack method, what is the specific sequence that `Stack 1` generates before pushing elements to `Stack 2`?**

**Answer:** Root -> Right -> Left.

**Q3: Why do we push the left child into `Stack 1` before the right child?** 

**Answer:** So that the right child sits on top of the stack and is processed first during the next iteration, fulfilling the Root -> Right -> Left pattern.

**Q4: How do you extract the final Postorder traversal answer?**

**Answer:** Once `Stack 1` is completely empty, you just pop every element out of `Stack 2` sequentially.

**Q5: What is the space complexity of this approach and why?** 

**Answer:** The space complexity is O(N) because `Stack 2` will eventually hold all N nodes of the tree at the same time before the final answer is extracted.
