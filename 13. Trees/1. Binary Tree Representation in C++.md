
## Key concepts

|**Term**|**Definition (your words)**|
|---|---|
|**Struct Node**|A custom data container in C++ grouping a value with logical pointers mapping to its children.|
|**Pointer (`*`)**|A variable storing the raw memory address of another node, bridging disjointed data blocks.|
|**`NULL` Assignment**|The explicit state of a pointer leading nowhere, structurally marking the bottom boundary of a tree path.|

## Structured notes

### C++ Struct Architecture

- A binary tree node fundamentally requires three properties: a state variable (`data`), a `left` pointer, and a `right` pointer (established).
-  [!example]

- ```cpp
    struct Node {
        int data;
        Node* left;
        Node* right;
    };
    ```
- Leaf nodes definitively cap a structural branch by aiming both their left and right pointers at `NULL` (consensus).
    

### Dynamic Allocation

- Memory for each new node must be generated dynamically at runtime using the `new` keyword (established).
    
- Node constructors systematically initialize incoming integer values while hardcoding both child pointers to `NULL` to prevent uninitialized memory access (established).
    
- Tree assembly requires explicitly mapping the parent's `left` or `right` pointer to the newly allocated child's memory address.

## Elaboration

> [!question] Why must binary trees be constructed dynamically via pointers instead of statically?
> 
> Unlike sequential arrays, trees are non-linear data structures whose terminal size and branching paths are rarely known at compile time. Relying on heap allocation via pointers (`new Node`) enables the hierarchy to scale arbitrarily during runtime and cleanly link disparate memory locations without requiring one massive, contiguous memory block.

## Quick recall

**Why are a newly generated node's left and right pointers explicitly assigned to `NULL` in the constructor?**

To safely establish that the node is currently a leaf. If left uninitialized, the pointers would contain garbage memory addresses, leading to fatal execution errors when traversed.

**What specific keyword in C++ is required to instantiate a tree node dynamically in memory?**

The `new` keyword, which claims space on the heap and returns the pointer to that specific block.

**If you possess a variable named `root`, how do you logically attach a new node to its left side?**

Assign the pointer returned by the new allocation to the parent's left property: `root->left = new Node(value);`.
