## The Basics

Level Order Traversal is an implementation of **Breadth-First Search (BFS)**. Instead of going deep into the tree, you explore it horizontally.

- **Sequence:** You print the root (level 1), then all nodes on level 2 from left to right, then all nodes on level 3 from left to right, and so on.
    

## The Data Structures

To implement Level Order Traversal iteratively, you need two primary data structures:

1. **A Queue (FIFO):** This acts as your waiting room. It keeps track of which nodes you need to process next, ensuring you process them in the correct left-to-right, top-to-bottom order.
    
2. **A List of Lists (or Vector of Vectors):** This will store your final answer. It groups the nodes level by level (e.g., `[[1], [2, 3], [4, 5, 6, 7]]`).
    

## The Core Algorithm (Iterative)

1. **Initialize:** Check if the root is `null` (return empty if so). Push the main `root` node into the Queue.
    
2. **Iterate:** While the Queue is not empty, start a loop.
    
3. **Capture Size:** At the start of each iteration, check the current `size` of the Queue. This size represents exactly how many nodes are on the current level.
    
4. **Process Level:** Run an inner loop exactly `size` times:
    
    - _Pop_ the front node out of the queue.
        
    - _Store_ its data in a temporary list for the current level.
        
    - _Check Left:_ If this node has a left child, push it into the queue.
        
    - _Check Right:_ If this node has a right child, push it into the queue.
        
5. **Save Level:** Once the inner loop finishes, add the temporary list to your final "List of Lists".
    
6. **Repeat:** The outer loop continues until the Queue is completely empty.
    

## Complexity

- **Time Complexity:** **O(N)**. Every single node in the binary tree is pushed into the queue once and popped out once.
    
- **Space Complexity:** **O(N)**. In the worst-case scenario (the widest part of a balanced tree), the queue will store approximately N/2 nodes at the same time. The space used by the returned 2D array is generally ignored in auxiliary space analysis since it is the required output.
    

## Active Recall

**Q1: What data structure is essential for implementing Level Order Traversal?** **Answer:** A Queue.

**Q2: How do you know how many nodes belong to the current level being processed?** **Answer:** By checking the size of the Queue immediately before you start popping nodes for that level.

**Q3: In what order should you push a node's children into the Queue?** **Answer:** Left child first, then right child. This ensures they are processed from left to right on the next level.

**Q4: If a node does not have any children, what do you push into the queue?** **Answer:** Nothing. You only push children if they exist (i.e., if they are not `null`).

**Q5: What are the time and space complexities for Level Order Traversal?** **Answer:** Time is O(N) and Space is O(N).
