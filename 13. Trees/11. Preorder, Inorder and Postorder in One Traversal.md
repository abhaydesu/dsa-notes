## The Basics

Instead of writing three separate algorithms to find the Preorder, Inorder, and Postorder sequences of a binary tree, you can execute all three simultaneously using **a single loop and a single Stack**.

## The Core Concept: The "State" Number

Every node in a binary tree goes through three states (or visits) during a full recursive traversal:

1. **First visit (State 1):** You arrive at the node for the first time. This is when **Preorder** is recorded. Then you go Left.
    
2. **Second visit (State 2):** You return to the node after finishing its left subtree. This is when **Inorder** is recorded. Then you go Right.
    
3. **Third visit (State 3):** You return to the node after finishing its right subtree. This is when **Postorder** is recorded. Then you are completely done with this node.
    

## The Data Structure

To track this iteratively, use a **Stack of Pairs**.

- Each element in the stack looks like: `(Node, State)`.
    
- Example: `(Node_A, 1)` means Node A is currently on its first visit.
    

## The Algorithm Rules

1. **Initialize:** Push `(Root, 1)` into the Stack.
    
2. **Iterate:** While the Stack is not empty, look at the top element `(Current Node, Current State)`.
    
3. **If State == 1 (Preorder Phase):**
    
    - Add the node's value to your **Preorder** list.
        
    - Increment the node's state to **2** inside the stack.
        
    - Check for a **Left** child. If it exists, push `(Left Child, 1)` onto the stack.
        
4. **If State == 2 (Inorder Phase):**
    
    - Add the node's value to your **Inorder** list.
        
    - Increment the node's state to **3** inside the stack.
        
    - Check for a **Right** child. If it exists, push `(Right Child, 1)` onto the stack.
        
5. **If State == 3 (Postorder Phase):**
    
    - Add the node's value to your **Postorder** list.
        
    - You are entirely finished with this node, so **Pop** it completely off the stack.
        

## Complexity

- **Time Complexity:** **O(3N)** which simplifies to **O(N)**. You are visiting and manipulating every node exactly three times (once for each state).
    
- **Space Complexity:** **O(4N)** which simplifies to **O(N)**. The stack requires O(N) space, and you are returning three separate lists (Preorder, Inorder, Postorder) which each take O(N) space.
    

## Active Recall

**Q1: To capture all three traversals in one loop, what data structure is used and what exactly does it hold?** **Answer:** A Stack of Pairs, where each pair holds the `(Node, State)` (the state is an integer 1, 2, or 3).

**Q2: What happens when the top node in the stack has a state of 1?** **Answer:** Its value is added to the Preorder list, its state is incremented to 2, and its left child (if it exists) is pushed onto the stack with a state of 1.

**Q3: When do you completely pop a node off the stack?** **Answer:** When its state reaches 3. Before popping, its value is added to the Postorder list.

**Q4: Which traversal list is updated during state 2?** **Answer:** The Inorder list. After updating the list, the state is incremented to 3 and the right child is pushed.

**Q5: Why is the time complexity considered O(3N)?** **Answer:** Because the `while` loop processes every single node exactly three times (once for state 1, once for state 2, and once for state 3) before finally popping it.
