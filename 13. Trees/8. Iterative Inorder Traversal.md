## The Basics

Inorder traversal dictates the sequence: **Left -> Root -> Right**. In an interview setting, you might be asked to solve this without using the built-in recursive call stack. To do this, you must simulate the recursion yourself using a custom **Stack** (Last-In, First-Out).

## The Core Concept

The recursive inorder traversal essentially plunges deep down the left side of the tree, remembering all the parent nodes it passed so it can come back to them later. In the iterative version, we do the exact same thing: we travel down the left side of the tree and manually push every node we encounter into our Stack. Once we hit a dead end (`null`), we pop the last node off the stack, process it (Print/Root), and then move to its Right child.

## The Algorithm

1. **Initialize:** Create an empty Stack and a variable called `node`, initialized to the `root` of the tree.
    
2. **Start Loop:** Create a `while(true)` loop.
    
3. **Go Left:** Inside the loop, check if the current `node` is not `null`.
    
    - If it is NOT `null`, push `node` onto the Stack.
        
    - Update `node = node.left` (plunge deeper left).
        
4. **Hit Null (Process & Go Right):** If the `node` IS `null`, it means you hit a dead end.
    
    - First, check if the Stack is empty. If it is, `break` the loop (you are finished).
        
    - If the Stack is not empty, `pop` the top node off the stack.
        
    - Print (or store) the popped node's value. (This is the **Left -> Root** part happening).
        
    - Update `node = popped_node.right` to explore the right side.
        
5. **Repeat:** The loop continues, naturally handling the Left -> Root -> Right sequence by utilizing the Stack.
    

## Complexity

- **Time Complexity:** **O(N)**. Every single node is pushed onto the stack exactly once and popped off the stack exactly once.
    
- **Space Complexity:** **O(H)**, where H is the height of the binary tree. In the absolute worst-case scenario (a heavily skewed tree where every node only has a left child), the stack would hold all nodes, making the space complexity **O(N)**.
    

## Active Recall

**Q1: What is the sequence for an Inorder Traversal?** 

**Answer:** Left -> Root -> Right.

**Q2: How do you simulate the recursive "memory" in an iterative approach?** 

**Answer:** By using a custom Stack data structure to push and save parent nodes as you travel down the tree.

**Q3: During the loop, what do you do as long as the current `node` is not `null`?** 

**Answer:** You push the current `node` onto the stack and move to the left (`node = node.left`).

**Q4: What happens immediately after a node is popped from the stack and printed?** 

**Answer:** The current `node` pointer is updated to the popped node's right child (`node = popped_node.right`).

**Q5: When does the main `while` loop finally terminate?** 

**Answer:** It terminates when the current `node` is `null` AND the Stack is completely empty.
