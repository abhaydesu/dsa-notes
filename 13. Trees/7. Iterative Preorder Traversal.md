## The Basics

Preorder traversal follows the sequence: **Root -> Left -> Right**. While the recursive method relies on the computer's built-in call stack to remember where to go next, an iterative approach requires you to manually control the flow using your own **Stack** data structure (Last-In, First-Out).

## The Core Algorithm

To replicate the recursive behavior iteratively, you push nodes onto a stack and pop them off to process them.

1. **Initialize:** Create an empty stack. If the tree's main root is not `null`, push it onto the stack.
    
2. **Iterate:** Start a `while` loop that continues as long as the stack is not empty.
    
3. **Pop & Process:** Pop the top node off the stack and print (or store) its data. This handles the "Root" portion of the traversal sequence.
    
4. **Push Right Child:** Check if the popped node has a right child. If yes, push it onto the stack.
    
5. **Push Left Child:** Check if the popped node has a left child. If yes, push it onto the stack.
    

**The Golden Rule for Iterative Preorder:** You MUST push the right child first, and the left child second. Because a stack operates on a Last-In, First-Out (LIFO) basis, putting the left child in last guarantees it will sit at the very top of the stack. This ensures the left child is popped and processed immediately on the next loop, perfectly maintaining the Root -> Left -> Right sequence.

## Complexity

- **Time Complexity:** **O(N)**. You are visiting, pushing, and popping every single node exactly once.
    
- **Space Complexity:** **O(H)**, where H is the height of the tree, because the stack only holds the necessary right-child references as it travels down the left side. In the worst-case scenario (a skewed, completely unbalanced tree), this becomes **O(N)**.
    

## Active Recall

**Q1: What specific data structure is required to implement Preorder Traversal iteratively?** 

**Answer:** A Stack.

**Q2: During the loop, in what exact order do you push a node's children into the stack?** 

**Answer:** You push the right child first, followed by the left child.

**Q3: Why must the right child be pushed into the stack before the left child?** 

**Answer:** Because a stack is Last-In, First-Out (LIFO). Pushing the left child last ensures it is at the top of the stack to be processed next, adhering to the Root -> Left -> Right traversal rule.

**Q4: What is the very first step before starting the `while` loop in this algorithm?** 

**Answer:** You must push the main root of the tree onto the stack (after ensuring the root is not `null`).
