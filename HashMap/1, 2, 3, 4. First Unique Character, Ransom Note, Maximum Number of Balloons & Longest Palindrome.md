> This lecture demonstrates how Hash Maps are fundamentally applied to string-based problems. While using Hash Maps with arrays or integers is straightforward, applying them to strings usually revolves around one core concept: **Letter Frequencies**. The instructor breaks down four progressive problems to illustrate how to construct, query, and manipulate these frequency maps to solve seemingly complex logical puzzles.

## Core Concept: Hash Maps in String Problems

When you see a string problem that requires you to analyze the _composition_ of the string (e.g., uniqueness, anagrams, character availability, palindromes) rather than contiguous subarrays, a Hash Map is almost always the answer.

**The Golden Rule:** In 95% of string-based Hash Map problems, the map will be constructed as:

- **Key:** Character (`char`)
- **Value:** Frequency/Count (`int`)

## Problem 1: First Unique Character in a String (LeetCode 387)

**Problem Statement:** Given a string `s`, find the first non-repeating character in it and return its index. If it does not exist, return `-1`.

### Intuition

A character is "unique" if it appears exactly **once** in the entire string.

To know if a character at index `i` is unique, you must have seen the _entire_ string first (otherwise, it might repeat at the very end).

### Approach

1. **Build the Frequency Map:** Iterate through the entire string once. For every character, increment its count in the Hash Map.
2. **Query the Map:** Iterate through the string a second time (from index `0` to `n-1`). Ask the Hash Map: _"What is the frequency of this character?"_
3. **Return:** The moment the Hash Map returns `1`, you have found the _first_ unique character. Return its index.

## Problem 2: Ransom Note (LeetCode 383)

**Problem Statement:** Given two strings `ransomNote` and `magazine`, return `true` if `ransomNote` can be constructed by using the letters from `magazine` and `false` otherwise. Each letter in `magazine` can only be used once.

### Intuition (The Job Requirement Analogy)

Think of `ransomNote` as a Job Description (Needs) and `magazine` as your Resume (Haves).

If the job requires a B.Tech with 70%, it doesn't matter if you have a Ph.D., an M.Tech, and 100% in 12th grade—if you failed B.Tech, you don't get the job.

- `ransomNote` dictates exactly what characters are needed and in what minimum quantity.
- `magazine` provides the available inventory.
- For the construction to be valid, for _every_ character in `ransomNote`, the frequency of that character in `magazine` must be $\ge$ the frequency needed.

### 💻 Approach

1. Create a frequency map for `ransomNote` (`needs_map`).
2. Create a frequency map for `magazine` (`haves_map`).
3. Iterate through the keys in `needs_map`. If for any character `c`, `haves_map[c] < needs_map[c]`, immediately return `false`.
4. If the loop completes without failing, return `true`.

## Problem 3: Maximum Number of Balloons (LeetCode 1189)

**Problem Statement:** Given a string `text`, you want to use the characters of `text` to form as many instances of the word `"balloon"` as possible. You can use each character in `text` at most once. Return the maximum number of instances that can be formed.

### Intuition (The Factory Analogy)

A factory produces pens, pencils, and toy cars to make a "Gift Box." If you have 100 toy cars, 10 pens, but only 8 pencils, you can only make 8 Gift Boxes.

_A factory is only as fast as its slowest worker. A production line is only as productive as its most scarce resource._

To spell `"balloon"`, you specifically need: `b:1, a:1, l:2, o:2, n:1`.

How many times can you form the word? It is dictated by the character you run out of first.

### 💻 Approach

1. Create a frequency map of the given `text`.
2. Calculate how many times the available inventory can satisfy the requirement for _each_ required letter.
    - `Times_Possible = Available_Count / Required_Count` (Integer division floors the result).
    - _Example:_ If you have 5 `'o'`s, and you need 2 per word: `5 / 2 = 2` times.
        
3. The maximum number of words you can form is the **minimum** of these `Times_Possible` across all required letters.

## Problem 4: Longest Palindrome (LeetCode 409)

**Problem Statement:** Given a string `s` which consists of lowercase or uppercase letters, return the length of the longest palindrome that can be built with those letters.

### Intuition & Logic

A palindrome reads the same forwards and backwards.

- **Even Length Palindrome:** Every character must appear in pairs (e.g., `abba`).
    
- **Odd Length Palindrome:** Every character must appear in pairs, _except for exactly one character_ which can sit alone in the absolute center (e.g., `abcba`).

You don't need to build the string; you only need to calculate the maximum length.

1. **Even Frequencies:** Any character with an even frequency can be entirely used to build the outer shell of the palindrome.
    
2. **Odd Frequencies:** If a character has an odd frequency (e.g., 5 `'c'`s), you cannot use all 5 symmetrically. However, you CAN use the largest even pairing (e.g., 4 `'c'`s) and leave 1 `'c'` discarded.
    
3. **The Centerpiece:** After pairing off everything possible, you will be left with several single characters (the discarded ones from the odd frequencies). You can pick **exactly one** of these leftovers to act as the center of the palindrome.

### Approach

1. Build a frequency map of the string `s`.
    
2. Initialize `length = 0` and a boolean flag `has_odd = false`.
    
3. Iterate through the frequency map:
    - If the frequency is **Even**: Add the entire frequency to `length`.
    - If the frequency is **Odd**: Add `frequency - 1` to `length`. Set `has_odd = true`.
        
4. If `has_odd` is `true`, add `1` to `length` (for the center character).
    
5. Return `length`.

## Active Recall

**Q: Why do string problems that involve finding anagrams, checking character combinations, or verifying subsets almost always require a Hash Map?**

**A:** Because these problems require knowing the exact _frequency_ of each character present in the string regardless of their chronological order. Hash Maps provide $O(1)$ lookups for these frequencies.

**Q: In the "Maximum Number of Balloons" problem, why is the final answer the _minimum_ of all the calculated available ratios?**

**A:** Because you cannot form a complete word if you are missing even a single required letter. The letter that runs out first acts as a bottleneck, strictly limiting the total number of complete words you can form.

**Q: When calculating the longest possible palindrome from a set of characters, how do you handle characters that appear an odd number of times (e.g., 5 times)?**

**A:** You take the largest even integer less than the frequency (e.g., `5 - 1 = 4`) and add it to the palindrome's length. The remaining single character is discarded, though one discarded character across the entire set can later be added to the absolute center of the palindrome.
