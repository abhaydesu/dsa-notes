## Universal Template for Variable Sliding Window

For variable sliding windows (where the length is unknown or dynamic), `low` and `high` pointers both start at `0`. The `high` pointer iterates steadily using a `for` loop, while the `low` pointer shrinks the window in an inner `while` loop whenever the window's "information" becomes invalid.

### Pseudo-code: Variable Sliding Window Template

```cpp
function variableSlidingWindowTemplate(arr):
    n = length of arr
    low = 0
    result = appropriate_initial_value // e.g., 0 for max, infinity for min
    
    // Maintain state (e.g., sum, hash map for frequency)
    state = initialize_state() 
    
    // Step 1: Expand the window
    for high = 0 to n - 1:
        
        // Step 2: Include the 'high' element in your state/information
        add_to_state(state, arr[high])
        
        // Step 3: Shrink the window if the information is INVALID
        while is_invalid(state):
            // Remove the 'low' element from your state
            remove_from_state(state, arr[low])
            low = low + 1
            
        // Step 4: If information is VALID, record the answer
        if is_valid(state):
            current_length = (high - low) + 1
            result = update_result(result, current_length)
            
    return result
```

**Complexity Analysis for this Template:**

- **Time Complexity:** $O(N)$. Even though there is a `while` loop inside a `for` loop, the `high` pointer travels from $0$ to $N$, and the `low` pointer travels from $0$ to at most $N$. Since `low` never resets, the total operations inside the `while` loop across the entire execution are at most $N$. Total operations $= O(N) + O(N) = O(N)$.
- **Space Complexity:** $O(1)$ to $O(K)$, depending on the state variable (like a hash map of max size 26 for alphabets, which reduces to $O(1)$ constant space).

##  Problem 1: Longest Substring with Exactly K Distinct Characters

**Problem Statement:** Given a string and an integer `k`, find the length of the longest substring that contains _exactly_ `k` distinct characters.

###  Logic & Intuition

- **State:** A Hash Map tracking the frequency of each character in the current window.
- **Information Check:** The number of unique characters is simply the **size of the hash map** (`map.size()`).
- **Invalid State:** If `map.size() > k`, we have too many distinct characters. We must shrink the window from the `low` end until the size drops back to `k`. (Note: We don't shrink if `map.size() < k` because moving `low` forward will only decrease or keep the size the same, taking us further from our goal of `k`).
- **Valid State:** When `map.size() == k`, the substring is valid, and we update our max length.

### Pseudo-code: Longest Substring with Exactly K Distinct
```cpp
function longestSubstringKDistinct(s, k):
    n = length of s
    low = 0
    max_len = 0
    freq_map = empty hash map
    
    for high = 0 to n - 1:
        // Include high character
        char_high = s[high]
        freq_map[char_high] = freq_map[char_high] + 1
        
        // Shrink if invalid (too many distinct characters)
        while size_of(freq_map) > k:
            char_low = s[low]
            freq_map[char_low] = freq_map[char_low] - 1
            
            // CRITICAL: Completely erase key if frequency hits 0
            if freq_map[char_low] == 0:
                remove_key_from_map(freq_map, char_low)
                
            low = low + 1
            
        // Check if exactly k distinct characters
        if size_of(freq_map) == k:
            current_len = (high - low) + 1
            max_len = max(max_len, current_len)
            
    return max_len
```

##  Problem 2: Fruits into Baskets

**Problem Statement:** You have a row of fruit trees represented by an array of integers (where each integer represents a fruit type). You have 2 baskets, and each basket can hold only 1 type of fruit. What is the maximum number of fruits you can pick from contiguous trees?

###  Logic & Intuition

If you translate the "real world" story into computer science terms, this is the _exact same problem_ as Problem 1.

- "Contiguous trees" $\rightarrow$ **Subarray/Substring**.
- "2 Baskets, each holding 1 type" $\rightarrow$ **At most 2 distinct elements**.
- "Maximum number of fruits" $\rightarrow$ **Longest length**.

**The Twist:** The condition is **At Most 2** distinct elements, not _Exactly_ 2. This means valid states are `map.size() == 1` OR `map.size() == 2`. We can just check if `map.size() <= 2` to update our result.

### Pseudo-code: Fruits into Baskets

```cpp
function totalFruit(fruits):
    n = length of fruits
    low = 0
    max_fruits = 0
    freq_map = empty hash map
    k = 2 // Maximum distinct fruits allowed
    
    for high = 0 to n - 1:
        fruit_high = fruits[high]
        freq_map[fruit_high] = freq_map[fruit_high] + 1
        
        // Shrink if we have more than 2 distinct fruit types
        while size_of(freq_map) > k:
            fruit_low = fruits[low]
            freq_map[fruit_low] = freq_map[fruit_low] - 1
            
            if freq_map[fruit_low] == 0:
                remove_key_from_map(freq_map, fruit_low)
                
            low = low + 1
            
        // Valid state is any state where distinct fruits <= 2
        // Since we already shrink when > 2, it is guaranteed to be <= 2 here
        current_len = (high - low) + 1
        max_fruits = max(max_fruits, current_len)
            
    return max_fruits
```

## Problem 3: Longest Substring Without Repeating Characters

**Problem Statement:** Given a string `s`, find the length of the longest substring without repeating characters.

###  Logic & Intuition

- How do we mathematically verify a string has "no repeating characters"?
- If a substring has a length of $W$, and the number of unique characters in that substring (the hash map size) is also $W$, then **every character is unique**.
- **Invalid State:** If the size of the hash map is _less_ than the length of the window (`map.size() < (high - low + 1)`), it means duplicates exist. We must shrink the window to remove the duplicate.
- **Valid State:** When `map.size() == (high - low + 1)`.

### Pseudo-code: Longest Substring Without Repeats
```cpp
function lengthOfLongestSubstring(s):
    n = length of s
    low = 0
    max_len = 0
    freq_map = empty hash map
    
    for high = 0 to n - 1:
        char_high = s[high]
        freq_map[char_high] = freq_map[char_high] + 1
        
        // Dynamic window size check
        window_size = (high - low) + 1
        
        // Shrink if invalid (duplicates exist)
        while size_of(freq_map) < window_size:
            char_low = s[low]
            freq_map[char_low] = freq_map[char_low] - 1
            
            if freq_map[char_low] == 0:
                remove_key_from_map(freq_map, char_low)
                
            low = low + 1
            // Recalculate window_size since 'low' moved
            window_size = (high - low) + 1 
            
        // Valid state (no duplicates)
        if size_of(freq_map) == window_size:
            max_len = max(max_len, window_size)
            
    return max_len
```

## Active Recall

**Q: In the universal variable sliding window template, why does shrinking the window (moving `low` forward) not cause the time complexity to become $O(N^2)$?**
**A:** Because the `low` pointer is independent of the `high` pointer's iterations. `low` never resets back to `0`; it only moves forward. Across the entire traversal of the array, `low` will increment at most $N$ times. Thus, the work is $O(N)$ for `high` plus $O(N)$ for `low`, resulting in a linear $O(N)$ complexity.

**Q: When using a Hash Map to track character frequencies in a window, why is it critical to completely delete the key when a character's frequency hits 0?**
**A:** The size of the Hash Map represents the number of _distinct_ characters in the window. If you leave a character in the map with a frequency of `0`, the map's size will artificially inflate the unique character count, breaking the logic of conditions like `map.size() == k`.

**Q: In the "Longest Substring with K Distinct Characters" problem, why do we use a `while` loop to shrink the window when `map.size() > k`, but we DO NOT shrink when `map.size() < k`?**
**A:** Shrinking the window (moving `low` forward) removes characters, which will either keep the number of distinct characters the same or decrease it. If we are already below the target `k` (`map.size() < k`), shrinking the window will take us further away from our goal. We need to expand the window (`high++`) to encounter new unique characters.

**Q: In the "Longest Substring Without Repeating Characters" problem, how do you mathematically prove that a window contains duplicates using only its length and a Hash Map?**
**A:** A window contains duplicates if the total number of characters in the window (`high - low + 1`) is strictly greater than the number of unique characters in the window (`map.size()`).
