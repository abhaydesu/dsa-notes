## When to Use the Two Pointers Pattern

The primary goal of mastering a pattern is being able to recognize it in unseen problems. The instructor provides a definitive "Flowchart" of indicators to look for in a problem description.

### 1. Data Structure Indicators

The problem must involve a linear data structure. If the problem involves graphs, trees, or stacks, Two Pointers is generally not the correct pattern.

- **Valid Structures:** Arrays or Linked Lists.
    

### 2. State Indicators (The Biggest Clue)

The state of the array is the most significant indicator for Two Pointers. Look for:

- **Already Sorted:** The array is explicitly given as sorted.
    
- **Beneficial to Sort:** The problem doesn't require the original index order, and sorting it first makes finding pairs/triplets vastly easier.
    

### 3. Action / Keyword Indicators

If the array is _not_ sorted, look for specific keywords combined with strict space constraints:

- **"Rearrange"** (e.g., sort specific elements, move zeros to end).
    
- **"Remove Duplicates"**
    
- **"Merge in place"**
    
- **Subarrays** (This often transitions into the Sliding Window subset).
    
- **Constraint:** "In-place" or $O(1)$ extra space. If you must modify an array without using extra memory, Two Pointers is almost certainly the required approach.
    

### 4. Goal Indicators

- **"Find more than one thing"**: Instead of finding a single target index, the problem asks you to find pairs (2 elements), triplets (3 elements), or quadruplets (4 elements).
    

##  Review of Solved Problems & Their Indicators

To solidify the flowchart, the instructor reviews how previously solved problems fit these exact criteria.

### Problem 1: Two Sum (Optimal Version)

- **Indicators:** Array + Beneficial to sort + Find a pair.
    
- **Pointer Movement:** `left` increments, `right` decrements (moving inward).
    

### Problem 2: Three Sum

- **Indicators:** Array + Beneficial to sort + Find a triplet.
    
- **Logic:** Loop + Two Sum (which makes it essentially a 3-pointer problem).
    

### Problem 3: Squares of a Sorted Array

- **Indicators:** Array + Already Sorted + In-place modification goal.
    
- **Logic:** Underneath the surface, it is structurally a "Merge Two Sorted Arrays" problem.
    

### Problem 4: Remove Duplicates

- **Indicators:** Array + Already Sorted + Keyword "Remove Duplicates" + In-place constraint.
    
- **Pointer Movement:** Both `slow` and `fast` pointers increment forward (same direction).
    

### Problem 5: Dutch National Flag (Sort Colors)

- **Indicators:** Array + Keyword "Rearrange" + In-place constraint ($O(1)$ space).
    
- **Pointer Movement:** Uses 3 pointers (`low`, `mid`, `high`) categorizing the array into sorted and unsorted regions.
    

##  Pointer Movement Variations

The Two-Pointer pattern is not just "left and right moving towards the center". The movement depends entirely on the problem's logic.

1. **Opposite Direction (Inward):** `left++` and `right--`. Used in Pair Sums, Reversing Arrays, etc.
    
2. **Same Direction (Fast/Slow):** `pointer1++` and `pointer2++`. Used in Remove Duplicates, Merging Arrays.
    
3. **Three Pointers:** `low`, `mid`, `high`. Used in complex sorting/partitioning like Dutch National Flag.
    

## Transition to Sliding Window

The instructor briefly introduces the next pattern in the series: **Sliding Window**.

- **What is it?** Sliding Window is a strict _subset_ of the Two Pointers pattern.
    
- **How it works:** It utilizes two pointers (a `low`/`start` and a `high`/`end`) that both move in the same direction. However, instead of evaluating individual elements, they evaluate the _window_ (the sub-array) between the two pointers. The window will expand and shrink dynamically based on the problem's conditions.
    

##  Active Recall

**Q: What are the two most fundamental linear data structures where the Two-Pointer pattern is applicable?**

**A:** Arrays and Linked Lists.

**Q: If an array is not sorted, what specific keywords or constraints strongly indicate a Two-Pointer approach?**

**A:** Keywords like "Rearrange", "Remove Duplicates", or "Merge", paired tightly with an "in-place" or $O(1)$ extra space constraint.

**Q: In the context of pointer movement, how does "Remove Duplicates" differ fundamentally from "Two Sum"?**

**A:** In "Two Sum", the pointers start at opposite ends and move inward (`left++`, `right--`). In "Remove Duplicates", both pointers start at the beginning and move in the same direction (`fast` scans ahead, `slow` trails behind).

**Q: How is the Sliding Window pattern related to the Two Pointers pattern?**

**A:** Sliding Window is a specific subset of the Two Pointers pattern where both pointers move in the same direction to define and evaluate a continuous sub-array (or "window") between them, which expands and shrinks as needed.
