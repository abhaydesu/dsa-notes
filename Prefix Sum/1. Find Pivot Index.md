Leetcode 724

**Problem Statement:** Given an array of integers `nums`, calculate the pivot index of this array. The pivot index is the index where the sum of all the numbers strictly to the left of the index is equal to the sum of all the numbers strictly to the index's right. (Return the leftmost pivot index, or -1 if none exists).

### Approach 1: Using Two Arrays (Brute Force Prefix)

1. Create a `Prefix` array of size $N$ passing left-to-right.
2. Create a `Suffix` array of size $N$ passing right-to-left.
3. Loop through the array from `0` to $N-1$. If `Prefix[i] == Suffix[i]`, return `i`.

- **Time:** $O(N)$
- **Space:** $O(N)$ (requires two extra arrays). _Interviewers will ask you to optimize this space._

### Approach 2: Optimal $O(1)$ Space (Running Variables)

We do not need to store the entire Prefix and Suffix arrays in memory. We only need the values _at the exact moment_ we are evaluating index `i`.

**The Core Mathematical Observation:**

At any index `i`, the array is split into three parts:

$$Left\_Sum + arr[i] + Right\_Sum = Total\_Sum$$

Therefore, if we pre-calculate the `Total_Sum` of the array once, we can dynamically calculate the `Right_Sum` at any point using simple algebra:

$$Right\_Sum = Total\_Sum - arr[i] - Left\_Sum$$

### Pseudo-code: Optimal Pivot Index

```cpp
function pivotIndex(arr):
    n = length of arr
    
    // Step 1: Calculate the total sum of the array
    total_sum = 0
    for i = 0 to n - 1:
        total_sum = total_sum + arr[i]
        
    // Step 2: Initialize the running 'left' prefix sum
    left_sum = 0
    
    // Step 3: Iterate and check the condition
    for i = 0 to n - 1:
        // Calculate the right sum dynamically
        right_sum = total_sum - arr[i] - left_sum
        
        // Check if it is a pivot
        if left_sum == right_sum:
            return i
            
        // Update left_sum for the NEXT iteration
        left_sum = left_sum + arr[i]
        
    return -1 // No pivot found
```
