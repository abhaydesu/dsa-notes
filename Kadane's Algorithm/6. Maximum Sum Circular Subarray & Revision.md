## Pattern Identification Flowchart

Before applying any logic, you must identify if Kadane's pattern is the right tool for the job.

1. **Data Structure:** Array (Must be an array. It does not apply to Linked Lists or Strings because the concept of numeric sums/products doesn't apply to them).
2. **Entity:** Subarray (Must be contiguous elements. It does not apply to subsequences).
3. **Goal:** Find a `Maximum` or `Minimum` value of an operation like `Sum` or `Product`.
4. **Condition/Twist (Optional):** The problem might include constraints or special conditions, such as:
    - Allowing 1 deletion.
    - Finding the Absolute sum.
    - The array is Circular.
5. **The Dealbreaker (Why not Sliding Window?):** The array contains a mix of **positive and negative** numbers, breaking the predictable expansion/shrinking logic of the sliding window.

## The Core Thought Process (Template Revision)

Kadane's algorithm is not just a 5-line code block; it is a **thought process** applied index by index.

At every index `i`, you must calculate the **Best Result Ending at Index $i$**.

To calculate this, you evaluate the choices available to `arr[i]`:

- **Choice 1:** Join the previous "Best Ending" (from index $i-1$) to extend the subarray.
- **Choice 2:** Start a brand new subarray containing only `arr[i]`.
    _(If there are twists like products or deletions, the number of choices might expand, but the logic of evaluating previous endings remains the same)._

Whichever choice yields the "Best" result (highest for max problems, lowest for min problems) becomes the new "Best Ending at $i$". The global answer is the "Best" of all the best endings.

## Variation 1: Maximum Absolute Sum of Any Subarray

**Problem Statement:** Find the maximum absolute sum of any contiguous subarray.

### Logic & Intuition

An absolute value converts negative numbers to positive (`abs(-10) = 10`).

Therefore, the maximum absolute sum can come from two sources:

1. A highly positive subarray sum.
2. A highly negative subarray sum.

You do not need a new algorithm for this. The problem simply asks you to find the **Maximum Subarray Sum** and the **Minimum Subarray Sum** using the standard Kadane's template, take the absolute values of both, and return whichever is larger.

### Pseudo-code
```cpp
function maxAbsoluteSum(arr):
    // Find Max Sum (Standard Kadane's)
    max_sum = findMaxSubArray(arr)
    
    // Find Min Sum (Standard Kadane's with min() instead of max())
    min_sum = findMinSubArray(arr)
    
    // Return the absolute maximum
    return max(max_sum, abs(min_sum))
```

## Variation 2: Maximum Sum Circular Subarray

**Problem Statement:** Given a circular integer array, find the maximum possible sum of a non-empty subarray. (A circular array means the end of the array connects back to the beginning).

### Logic & Intuition

Because the array is circular, the maximum subarray can take two forms:

- **Case 1: Standard (Not Wrapped)**
    The maximum sum is entirely contained within the standard bounds of the array (e.g., indices 2 to 5). This is identical to the standard Maximum Subarray problem.
- **Case 2: Wrapped (Circular)**
    The maximum sum wraps around the end of the array to the beginning (e.g., indices `[n-2, n-1, 0, 1]`).

**The Mathematical Trick for Case 2:**

If the "Max Sum" elements wrap around the edges, what is left in the middle of the array?

The elements left in the middle _must_ be the "worst" possible elements—the **Minimum Subarray Sum**.

Therefore, you can mathematically calculate the wrapped Maximum Sum by taking the **Total Sum of the Array** and subtracting the **Minimum Subarray Sum**.

### Pseudo-code
```cpp
function maxSubarraySumCircular(arr):
    n = length of arr
    
    // Step 1: Calculate Standard Max Sum (Case 1)
    max_sum = findMaxSubArray(arr)
    
    // Step 2: Calculate Standard Min Sum
    min_sum = findMinSubArray(arr)
    
    // Step 3: Calculate the Total Sum of the array
    total_sum = 0
    for i = 0 to n - 1:
        total_sum = total_sum + arr[i]
        
    // Step 4: Calculate the Wrapped Max Sum (Case 2)
    wrapped_max_sum = total_sum - min_sum
    
    // Edge Case: If all elements are negative
    // total_sum will equal min_sum, making wrapped_max_sum = 0.
    // An empty array is not allowed, so we must return max_sum.
    if max_sum < 0:
        return max_sum
        
    // Step 5: Return the maximum of Case 1 and Case 2
    return max(max_sum, wrapped_max_sum)
```

## Active Recall

**Q: In the core thought process of Kadane's Algorithm, what two primary choices are evaluated at every index `i` to calculate the "Best Ending"?**

**A:** 1) Join the "Best Ending" from the previous index `i-1` to extend the subarray. 2) Reject the previous subarray and start a new one containing only the current element `arr[i]`.

**Q: Why does the Maximum Absolute Sum problem not require a unique, custom implementation of Kadane's algorithm?**

**A:** Because taking the absolute value of a sum means the maximum result will always originate from either the highest positive sum or the lowest negative sum. You can simply run the standard Max Subarray and Min Subarray algorithms independently, take the absolute value of both results, and return the maximum.

**Q: If the maximum subarray in a circular array wraps around the ends of the array, what does that mathematically imply about the contiguous elements remaining in the middle of the array?**

**A:** It implies that the contiguous elements remaining in the middle form the **Minimum Subarray Sum**. Because the best elements wrapped around the edges, the worst elements were left untouched in the center.

**Q: How do you mathematically calculate the sum of a "wrapped" maximum subarray using the Minimum Subarray Sum?**

**A:** You calculate the `Total Sum` of the entire array and subtract the `Minimum Subarray Sum` (`Total Sum - Min Sum`). This "cuts out" the worst part of the array, leaving only the wrapped maximum sum.
