**Problem Statement:** Given a set of non-overlapping intervals sorted by their start times, insert `newInterval` and merge any overlapping intervals.
## Intuition & The "3 Parts" Analogy

When inserting `newInterval`, every existing interval falls into one of **three parts**:

```text
[ BEFORE ] [ OVERLAPPING WITH NEW ] [ AFTER ]
```

### Part 1 — Completely Before

An interval is before `newInterval` if:

```cpp
intervals[i][1] < newInterval[0]
```

Example:

```text
[1,2]       [5,7]
             ↑
        newInterval
```

There is no overlap, so simply add `[1,2]`.
### Part 2 — Overlapping

An interval overlaps `newInterval` if:

```cpp
intervals[i][0] <= newInterval[1]
```

Merge it by expanding `newInterval`:

```cpp
newInterval[0] = min(newInterval[0], intervals[i][0]);
newInterval[1] = max(newInterval[1], intervals[i][1]);
```
### Part 3 — Completely After

Once we've finished processing overlapping intervals, everything remaining is after `newInterval`.

Simply add them to the result.
# Approach 1 — Insert First, Then Merge

This is the approach you initially came up with.
#### Step 1

Find the correct position for `newInterval` based on its start:

```cpp
if (newInterval[0] <= intervals[i][0])
```

Then physically insert it:

```cpp
intervals.insert(intervals.begin() + i, newInterval);
```

If it belongs at the end:

```cpp
intervals.push_back(newInterval);
```

#### Step 2

Run a normal **Merge Intervals** algorithm over the resulting vector.

The merge logic is:

```cpp
if (end1 >= start2) {
    end1 = max(end1, end2);
}
else {
    res.push_back({start1, end1});
    start1 = start2;
    end1 = end2;
}
```

### Code
```cpp
class Solution {
public:
    vector<vector<int>> mergeIntervals(vector<vector<int>> intervals) {
        int n = intervals.size();

        int start1 = intervals[0][0];
        int end1 = intervals[0][1];

        vector<vector<int>> res;

        for (int i = 1; i < n; i++) {
            int start2 = intervals[i][0];
            int end2 = intervals[i][1];

            if (end1 >= start2) {
                end1 = max(end1, end2);
            }
            else {
                res.push_back({start1, end1});
                start1 = start2;
                end1 = end2;
            }
        }

        res.push_back({start1, end1});
        return res;
    }

    vector<vector<int>> insert(vector<vector<int>>& intervals,
                               vector<int>& newInterval) {

        int n = intervals.size();
        bool inserted = false;

        if (intervals.empty())
            return {newInterval};

        for (int i = 0; i < n; i++) {
            if (newInterval[0] <= intervals[i][0] && !inserted) {
                intervals.insert(intervals.begin() + i, newInterval);
                inserted = true;
            }
        }

        if (!inserted)
            intervals.push_back(newInterval);

        return mergeIntervals(intervals);
    }
};
```

### Complexity

- **Time:** `O(N)`
- **Space:** `O(N)` for the result

Although `vector.insert()` itself can take `O(N)`, the subsequent merge is also `O(N)`, so the overall complexity remains `O(N)`.

# Approach 2 — Single-Pass Optimal Solution

We don't actually need to insert `newInterval` into the vector.
Instead, process the intervals directly in **three phases**.
#### Phase 1 — Before

```cpp
while (i < n && intervals[i][1] < newInterval[0])
```

These intervals cannot overlap with `newInterval`.

Add them directly:

```cpp
res.push_back(intervals[i]);
```

#### Phase 2 — Overlapping

```cpp
while (i < n && intervals[i][0] <= newInterval[1])
```

Merge every overlapping interval into `newInterval`:

```cpp
newInterval[0] = min(newInterval[0], intervals[i][0]);
newInterval[1] = max(newInterval[1], intervals[i][1]);
```

After this loop, `newInterval` represents the **entire merged interval**.

Add it:

```cpp
res.push_back(newInterval);
```
#### Phase 3 — After

Everything remaining is guaranteed to be after `newInterval`.

```cpp
while (i < n) {
    res.push_back(intervals[i]);
    i++;
}
```
##  Single-Pass Optimal Code

```cpp
class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals,
                               vector<int>& newInterval) {

        vector<vector<int>> res;

        int i = 0;
        int n = intervals.size();

        // 1. Intervals completely before newInterval
        while (i < n && intervals[i][1] < newInterval[0]) {
            res.push_back(intervals[i]);
            i++;
        }

        // 2. Merge overlapping intervals
        while (i < n && intervals[i][0] <= newInterval[1]) {
            newInterval[0] = min(newInterval[0], intervals[i][0]);
            newInterval[1] = max(newInterval[1], intervals[i][1]);
            i++;
        }

        res.push_back(newInterval);

        // 3. Intervals completely after newInterval
        while (i < n) {
            res.push_back(intervals[i]);
            i++;
        }

        return res;
    }
};
```

# Dry Run

```text
intervals = [[1,2], [3,5], [6,7], [8,10], [12,16]]
newInterval = [4,8]
```

### Phase 1 — Before

```text
[1,2]
```

Since:

```text
2 < 4
```

add it.

```text
res = [[1,2]]
```

### Phase 2 — Overlapping

`[3,5]` overlaps:

```text
[4,8] + [3,5] → [3,8]
```

`[6,7]` overlaps:

```text
[3,8] + [6,7] → [3,8]
```

`[8,10]` overlaps:

```text
[3,8] + [8,10] → [3,10]
```

So:

```text
res = [[1,2], [3,10]]
```

### Phase 3 — After

`[12,16]` is completely after the merged interval.

```text
res = [[1,2], [3,10], [12,16]]
```
# Approach Comparison

| **Insert + Merge Single Pass** | **Insert + Merge** | **Single Pass** |
|---|---|---|
| **Main idea** | Insert first, then merge | Directly build result |
| **Physically modifies `intervals`** | Yes | No |
| **Passes** | Insert + merge | Single traversal |
| **Time** | `O(N)` | `O(N)` |
| **Space** | `O(N)` | `O(N)` |
| **Simplicity** | Easier if you know Merge Intervals | More specialized |
| **Recommended** | Good first solution | **Best approach for LC 57** |

Both are **O(N)** asymptotically, so the single-pass approach isn't asymptotically faster. Its advantage is that it avoids unnecessary insertion/shifting and directly solves the structure of this particular problem.
## Complexity Analysis

### Single-Pass Approach

- **Time Complexity:** `O(N)` — every interval is processed once.
- **Space Complexity:** `O(N)` — the result vector stores the answer.
## Active Recall

**Q: What are the three categories of intervals?**
**A:**
```text
1. Completely before newInterval
2. Overlapping with newInterval
3. Completely after newInterval
```

**Q: How do we identify an interval completely before `newInterval`?**
**A:**
```cpp
intervals[i][1] < newInterval[0]
```

Its end is before the new interval's start.

**Q: How do we identify an overlapping interval?**
**A:**
```cpp
intervals[i][0] <= newInterval[1]
```

Its start is at or before the current end of `newInterval`.

**Q: How do we merge an overlapping interval?**
**A:**
```cpp
newInterval[0] = min(newInterval[0], intervals[i][0]);
newInterval[1] = max(newInterval[1], intervals[i][1]);
```

**Q: Why don't we need to explicitly check for the "after" condition?**
**A:**
Once the first two loops finish, any remaining interval cannot be before or overlapping `newInterval`, so it must be after it.

**Q: Why is the single-pass approach preferred?**
**A:**
Because we don't need to physically insert `newInterval` into the vector and then run a separate merge algorithm. We directly construct the answer in one traversal.

**Q: What is the key pattern to remember?**
**A:**
```text
BEFORE → add directly

OVERLAP → expand newInterval

AFTER → add directly
```

```text
[ BEFORE ][ MERGE ][ AFTER ]
             ↑
        newInterval
```
