## Problem Statement: Interval List Intersections

You are given two lists of closed intervals, `firstList` and `secondList`, where `firstList[i] = [start_i, end_i]` and `secondList[j] = [start_j, end_j]`. Each list of intervals is pairwise **disjoint** (no overlapping intervals within the same list) and sorted by their `start` times.

**Task:** Return the intersection of these two interval lists.

**Example:**

- `A = [[0,2], [5,10], [13,23]]`
- `B = [[1,2], [5,5], [8,10]]`
- **Intersections:** `[[1,2], [5,5], [8,10]]`

## Logic & Intuition

### 1. Why Two Pointers?

Whenever you are given **two arrays** that are already **sorted**, and you need to compare them to merge, find intersections, or calculate differences, you must immediately think of the **Two Pointers** technique (e.g., `i` pointing to `firstList`, `j` pointing to `secondList`).

You will compare the interval at `A[i]` with the interval at `B[j]`.

### 2. How to Detect an Overlap (Intersection)?

Let $S_1, E_1$ be the start and end of `A[i]`.

Let $S_2, E_2$ be the start and end of `B[j]`.

To find if they overlap, we must first figure out which interval starts first.

- If $S_1 \le S_2$: We use the standard overlap logic: If $E_1 \ge S_2$, they overlap.
- If $S_2 < S_1$: The roles are reversed. We must check if $E_2 \ge S_1$.

**The Output of the Intersection:**

If they overlap, what is the exact range of the overlapping segment?

Think of a timeline: You are free from 1 PM to 6 PM. Your friend is free from 2 PM to 7 PM. When are you _both_ free?

- You can't meet before 2 PM (friend isn't there). So the start is the **latest** of the two start times.
- You must leave at 6 PM (you aren't there after). So the end is the **earliest** of the two end times.
- **Intersection Formula:** `[ max(S1, S2), min(E1, E2) ]`

### 3. Pointer Movement: Who Advances?

After comparing `A[i]` and `B[j]`, you must advance either `i` or `j` to continue checking the lists. How do you decide?

**The "Leaving the Party" Analogy:**

You are at a party from 1 PM to 10 PM. Your friend is there from 2 PM to 3 PM.

Your friend leaves the party at 3 PM. Their interval is completely exhausted. However, you are still at the party until 10 PM! You might intersect with _another_ friend who arrives at 4 PM.

Therefore, the pointer that advances must be the one whose interval **ends first**.

- If $E_1 < E_2$: Increment `i`.
- If $E_2 \le E_1$: Increment `j`.

## Pseudo-code: Interval List Intersections
```cpp
function intervalIntersection(A, B):
    i = 0
    j = 0
    n = length of A
    m = length of B
    result = empty list
    
    // Continue while BOTH lists have intervals left to compare
    while i < n and j < m:
        // Get the start and end times for the current pointers
        S1 = A[i][0]
        E1 = A[i][1]
        
        S2 = B[j][0]
        E2 = B[j][1]
        
        // --------------------------------------------------------
        // STEP 1: Check for Overlap
        // --------------------------------------------------------
        has_overlap = false
        
        if S1 <= S2:
            // A starts first (or simultaneously)
            if E1 >= S2:
                has_overlap = true
        else:
            // B starts first
            if E2 >= S1:
                has_overlap = true
                
        // --------------------------------------------------------
        // STEP 2: Calculate and Store the Intersection
        // --------------------------------------------------------
        if has_overlap == true:
            intersection_start = max(S1, S2)
            intersection_end = min(E1, E2)
            result.append([intersection_start, intersection_end])
            
        // --------------------------------------------------------
        // STEP 3: Pointer Movement
        // --------------------------------------------------------
        // Advance the pointer of the interval that ends FIRST
        if E1 <= E2:
            i = i + 1
        else:
            j = j + 1
            
    return result
```

_(External Note: The overlap check can be simplified logically in many languages to a single condition without checking which starts first: `max(S1, S2) <= min(E1, E2)`. If this is true, they overlap, and those two bounds form the intersection. The instructor's explicit if/else approach is excellent for understanding the granular logic)._

## Complexity Analysis

- **Time Complexity:** $O(N + M)$. In the worst-case scenario, every iteration of the `while` loop increments either `i` or `j`. Therefore, the loop will run at most $N + M$ times. Inside the loop, all operations (comparisons, max/min, pushing to result) take $O(1)$ constant time.
- **Space Complexity:** $O(1)$ auxiliary space. We do not use any extra space other than the list required to return the output.

## Active Recall

**Q: Why do we use the Two Pointers technique for the "Interval List Intersections" problem instead of a single loop?**

**A:** Because we are given _two_ distinct, sorted arrays of intervals. To find overlapping regions between two separate sorted sources efficiently, we must use two independent pointers (`i` and `j`) to compare the current interval of one list against the current interval of the other.

**Q: When calculating the exact bounds of an intersecting interval, why do we use `max(start1, start2)` and `min(end1, end2)`?**

**A:** Because an intersection requires _both_ intervals to be active simultaneously. The intersection cannot begin until the later of the two start times has occurred (`max`). Conversely, the intersection must end the moment the earliest of the two intervals ends (`min`).

**Q: After comparing `A[i]` and `B[j]`, how do we decide whether to increment `i` or `j`?**

**A:** We advance the pointer whose interval ends earliest. The interval that ends first is completely exhausted and cannot possibly intersect with any future intervals. The interval that ends later might still be active and capable of intersecting with the next interval in the other list.

**Q: Why does the `while` loop condition require `i < n AND j < m` instead of `OR`?**

**A:** Because an intersection requires an active interval from _both_ lists. If one list runs out of intervals, it is impossible to form any further intersections, so we can immediately terminate the loop.
