## Pseudo-code: Merge Intervals (LeetCode 56)
```cpp
function mergeIntervals(intervals):
    n = length of intervals
    if n == 0: return empty list
    
    // Step 1: Sort the intervals based on the start value (intervals[i][0])
    sort(intervals by intervals[i][0])
    
    result = empty list
    
    // Step 2: Initialize trackers with the very first interval
    start1 = intervals[0][0]
    end1 = intervals[0][1]
    
    // Step 3: Iterate through the remaining intervals
    for i = 1 to n - 1:
        start2 = intervals[i][0]
        end2 = intervals[i][1]
        
        // Check for overlap
        if end1 >= start2:
            // MERGE: Update the current running interval
            // start1 remains the same
            end1 = max(end1, end2)
            
        else:
            // NO OVERLAP: The running interval is complete. 
            // Save it to the result list.
            result.append([start1, end1])
            
            // Start a new running interval using the current element
            start1 = start2
            end1 = end2
            
    // Step 4: Add the final running interval to the result
    // (The loop finishes before the last element gets appended)
    result.append([start1, end1])
    
    return result
```

### Complexity Analysis

- **Time Complexity:** $O(N \log N)$. The dominant operation is sorting the array at the very beginning. The subsequent linear scan takes $O(N)$ time.
    
- **Space Complexity:** $O(N)$ (or $O(\log N)$ depending on the sorting algorithm used under the hood, plus the space required for the output array).
