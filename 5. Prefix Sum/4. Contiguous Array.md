**Problem Statement:** Given a binary array `nums`, return the maximum length of a contiguous subarray with an equal number of `0`s and `1`s.
## Intuition & The "Green/Red Part" Analogy

We want a **Green Part** where:

```text
number of 0s = number of 1s
```

Instead of separately counting `0`s and `1`s, convert:

```text
0 → -1
1 → +1
```

Now equal `0`s and `1`s means the subarray has **sum = 0**.

Example:

```text
[0, 1, 0, 1]
 ↓  ↓  ↓  ↓
[-1, 1, -1, 1]

sum = 0
```

So the problem becomes:

> **Find the longest contiguous subarray with sum `0`.**

---

## The Prefix Sum Epiphany

Suppose the prefix sum at an earlier index `j` is `5`, and the prefix sum at our current index `i` is also `5`.

```text
Current Prefix Sum - Previous Prefix Sum
= 5 - 5
= 0
```

Therefore, the subarray between `j + 1` and `i` has sum `0`.

Since we converted:

```text
0 → -1
1 → +1
```

this guarantees that the subarray contains an equal number of `0`s and `1`s.

**Key idea:**

> If the **same prefix sum** appears twice, the elements between those positions form a valid subarray.

---

## The Hash Map Logic (Longest vs. Count)

We store:

```text
<Prefix Sum, First Index Seen>
```

Why the **first** index?

The length is:

```text
current_index - previous_index
```

To maximize the length, we want the previous index to be as small as possible.

Therefore:

> If a prefix sum already exists in the map, **DO NOT update its index**.

### The Edge Case: `Sum == 0`

We initialize:

```cpp
mp[0] = -1;
```

This represents a prefix sum of `0` occurring **before the array starts**.

So if the sum becomes `0` at index `i`:

```text
length = i - (-1)
       = i + 1
```

This automatically handles valid subarrays starting at index `0`.

---

## Pseudo-code: Longest Subarray with Equal 0s and 1s
```cpp
function findMaxLength(nums):
    sum = 0
    max_len = 0

    // Store <Prefix Sum, First Index>
    diff_map = {0 : -1}

    for i = 0 to n - 1:

        if nums[i] == 0:
            sum = sum - 1
        else:
            sum = sum + 1

        if diff_map contains sum:
            current_len = i - diff_map[sum]
            max_len = max(max_len, current_len)

        else:
            // Store only the first occurrence
            diff_map[sum] = i

    return max_len
```

## Optimal C++ Solution

```cpp
class Solution {
public:
    int findMaxLength(vector<int>& nums) {
        int sum = 0, res = 0;

        unordered_map<int, int> mp;
        mp[0] = -1;

        for (int i = 0; i < nums.size(); i++) {

            if (nums[i] == 0)
                sum--;
            else
                sum++;

            if (mp.find(sum) != mp.end()) {
                res = max(res, i - mp[sum]);
            }
            else {
                mp[sum] = i;
            }
        }

        return res;
    }
};
```

---

## Complexity Analysis

- **Time Complexity:** `O(N)` — one pass through the array.
- **Space Complexity:** `O(N)` — Hash Map can contain up to `N` different prefix sums.

## Active Recall

**Q: Why do we convert `0 → -1` and `1 → +1`?**

**A:** Because equal numbers of `0`s and `1`s then become a subarray with sum `0`.

---

**Q: If the same prefix sum occurs at indices `j` and `i`, what does that guarantee?**

**A:** The subarray from `j + 1` to `i` has sum `0`, meaning it has equal numbers of `0`s and `1`s.

---

**Q: Why do we store only the first occurrence of a prefix sum?**

**A:** We want the **longest** subarray. Keeping the earliest index maximizes `i - j`.

---

**Q: Why do we initialize `mp[0] = -1`?**

**A:** It represents a prefix sum of `0` before the array starts, allowing us to correctly calculate subarrays beginning at index `0`.

---

**Q: Why do we search for `mp[sum]` instead of `mp[-sum]`?**

**A:** Because we need:

```text
current_prefix - previous_prefix = 0
```

so:

```text
previous_prefix = current_prefix
```

Therefore, we look for the **same prefix sum**.
