### 1. Problem Statement

- **Input:** A string consisting of lowercase letters (e.g., `"ab"`).
    
- **Goal:** Print all permutations of the string where each character can either remain lowercase or be converted to uppercase.
    
- **Output for `"ab"`:**
    
    - `"ab"`
        
    - `"aB"`
        
    - `"Ab"`
        
    - `"AB"`
        

### 2. Identifying the Choices (The Core Logic)

For every single character in the input string, we have exactly **two choices**:

1. **Keep it lowercase** (as it is).
    
2. **Convert it to uppercase**.
    

Because every character presents two distinct choices, we can build a binary recursive tree using the Input-Output method.

### 3. Designing the Recursive Tree

- **Initial Setup (in `main`):**
    
    - `Input = "ab"`
        
    - `Output = ""`
        
- **Branching (The Recursion):**
    
    - At the root (`In = "ab"`, `Out = ""`), we look at the first character: `'a'`.
        
    - **Branch 1 (Lowercase):** Add `'a'` to the output. `Out` becomes `"a"`. Remove `'a'` from input. New `In = "b"`.
        
    - **Branch 2 (Uppercase):** Add `'A'` to the output. `Out` becomes `"A"`. Remove `'a'` from input. New `In = "b"`.
        
    - Repeat this branching for the next character `'b'` on both of the newly created branches.
        
- **Base Condition:**
    
    - When the `Input` string becomes completely empty (length is 0), we have reached a leaf node. We simply print the `Output` string and return.
        

### 4. Code Structure Breakdown

```cpp
void solve(string ip, string op) {
    // 1. Base Condition
    if (ip.length() == 0) {
        cout << op << endl;
        return; // CRITICAL: Do not forget to return!
    }
    
    // 2. Create the two choice branches
    string op1 = op;
    string op2 = op;
    
    // Choice 1: Include as lowercase (as it currently is)
    op1.push_back(ip[0]);
    
    // Choice 2: Include as uppercase
    // toupper() converts a lowercase char to uppercase
    op2.push_back(toupper(ip[0]));
    
    // 3. Make the input smaller by removing the processed character
    ip.erase(ip.begin() + 0);
    
    // 4. Recursive calls
    solve(ip, op1);
    solve(ip, op2);
}
```

## Active Recall

**1. What are the two choices available for every character in this specific permutation problem?**

_Answer:_ The two choices are to either include the character in the output string as a lowercase letter, or to include it as an uppercase letter.

**2. In C++, what built-in function is used to convert a lowercase character to an uppercase character?** 

_Answer:_ The `toupper()` function.

**3. What happens if you forget to write the `return` statement inside the Base Condition?** 

_Answer:_ If you forget `return`, the function will continue executing the code below the base condition. It will attempt to access `ip[0]` (the first character of the input string), but since the input string is empty, it will cause an out-of-bounds error resulting in a **Segmentation Fault**.

**4. How do you reduce the size of the input string before making the recursive calls?**

_Answer:_ You remove the first character from the input string using the `erase` function, typically written as `ip.erase(ip.begin() + 0)`.
