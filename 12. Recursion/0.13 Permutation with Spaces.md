### 1. Problem Statement

- **Input:** A string of characters, e.g., `"ABC"`.
    
- **Goal:** Print all possible permutations of the string where spaces can be inserted between the characters.
    
- **Important Constraint:** Spaces can _only_ be placed _between_ characters. You cannot place a space before the first character (e.g., `" ABC"`) or after the last character (e.g., `"ABC "`).
    
- **Output for "ABC":**
    
    - `"A B C"`
        
    - `"A BC"`
        
    - `"AB C"`
        
    - `"ABC"`
        

### 2. Identifying the Choices (The Core Logic)

Because we cannot put a space before the first character, the first character (`'A'`) will _always_ just be placed in our output string as is. The real decisions start from the _second_ character onwards. For every subsequent character (like `'B'` and `'C'`), we have exactly **two choices**:

1. **Include with a space:** Add a space, and then add the character (e.g., `"A"` becomes `"A B"`).
    
2. **Include without a space:** Add the character directly (e.g., `"A"` becomes `"AB"`).
    

### 3. Designing the Recursive Tree (Input-Output Method)

- **Initial Setup (in `main`):**
    
    - `Input = "ABC"`
        
    - `Output = ""`
        
    - Since the first character never has a space before it, we forcefully push it to the output and remove it from the input _before_ starting the recursion.
        
    - New `Input = "BC"`
        
    - New `Output = "A"`
        
- **Branching (The Recursion):**
    
    - At the root (`In = "BC"`, `Out = "A"`), we look at the first character of the input: `'B'`.
        
    - **Branch 1 (With Space):** `Out` becomes `"A B"`. Remove `'B'` from input. New `In = "C"`.
        
    - **Branch 2 (Without Space):** `Out` becomes `"AB"`. Remove `'B'` from input. New `In = "C"`.
        
    - Repeat this branching for `'C'`.
        
- **Base Condition:**
    
    - When the `Input` string becomes completely empty (length is 0), we have reached a leaf node. We print the `Output` string and return.
        

### 4. Code Structure Breakdown

```cpp
void solve(string ip, string op) {
    // 1. Base Condition
    if (ip.length() == 0) {
        cout << op << endl;
        return;
    }
    
    // 2. Create the two choice branches
    string op1 = op;
    string op2 = op;
    
    // Choice 1: Include with space
    op1.push_back(' ');
    op1.push_back(ip[0]);
    
    // Choice 2: Include without space
    op2.push_back(ip[0]);
    
    // 3. Make the input smaller
    ip.erase(ip.begin() + 0);
    
    // 4. Recursive calls
    solve(ip, op1);
    solve(ip, op2);
}
```

## Active Recall

**1. Why do we forcefully push the first character of the input string to the output string _before_ calling the recursive function?** 

_Answer:_ Because the problem statement strictly implies that spaces can only be placed _between_ characters. We can never have a leading space before the very first character. By moving the first character manually, the recursive function only has to make decisions (space or no space) for the remaining characters.

**2. For every character processed inside the recursive function, what are the two choices represented by the branches of the recursive tree?** 

_Answer:_

1. Include the current character into the output string _with_ a space preceding it.
    
2. Include the current character into the output string _without_ a space preceding it.
    

**3. What is the Base Condition for this recursive function, and how do you identify it from the Recursive Tree?** 

_Answer:_ The Base Condition is when the input string (`ip`) becomes empty (`ip.length() == 0`). Looking at the recursive tree, the leaf nodes (where we get our final permutation answers) are reached exactly when there are no more characters left in the input string to process.

**4. Before making the two recursive calls (`solve(ip, op1)` and `solve(ip, op2)`), what operation must be performed on the input string (`ip`)?** 

_Answer:_ You must erase the first character of the input string (`ip.erase(ip.begin() + 0)`). This is because you have just processed that character (added it to `op1` and `op2`), and you need to pass the smaller, remaining input to the next recursive calls.
