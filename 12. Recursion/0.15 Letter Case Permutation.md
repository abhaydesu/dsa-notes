### 1. Problem Statement

- **Input:** A string consisting of both letters (alphabets) and digits (numbers) in any case (e.g., `"a1B2"`).
    
- **Goal:** Print or return all possible permutations where the _letters_ can be transformed to either lowercase or uppercase. The _digits_ must remain exactly as they are.
    
- **Output for `"a1B2"`:**
    
    - `"a1b2"`
        
    - `"a1B2"`
        
    - `"A1b2"`
        
    - `"A1B2"`
        

### 2. Identifying the Choices (The Core Logic)

Because the string contains both letters and digits, we cannot blindly branch into two paths for every single character. We must first **check the type** of the character:

- **Condition A: It is a Digit (e.g., '1', '2')**
    
    - We have only **ONE choice**: Include the digit in the output exactly as it is.
        
- **Condition B: It is an Alphabet (e.g., 'a', 'B')**
    
    - We have **TWO choices**:
        
        1. Include the character in its lowercase form (using `tolower()`).
            
        2. Include the character in its uppercase form (using `toupper()`).
            

### 3. Designing the Recursive Tree

- **Initial Setup:** `In = "a1b2"`, `Out = ""`
    
- **First Level (Processing 'a'):**
    
    - 'a' is an alphabet -> 2 branches.
        
    - Branch 1: `Out = "a"`, `In = "1b2"`
        
    - Branch 2: `Out = "A"`, `In = "1b2"`
        
- **Second Level (Processing '1'):**
    
    - '1' is a digit -> Only 1 branch for each node.
        
    - From `"a"`: `Out = "a1"`, `In = "b2"`
        
    - From `"A"`: `Out = "A1"`, `In = "b2"`
        
- **Base Condition:**
    
    - When the Input string becomes completely empty (`ip.length() == 0`), push the Output string into the result vector and `return`.
        

### 4. Code Structure Breakdown

```cpp
void solve(string ip, string op, vector<string>& v) {
    // 1. Base Condition
    if (ip.length() == 0) {
        v.push_back(op);
        return;
    }
    
    // 2. Check if the current character is an alphabet
    if (isalpha(ip[0])) {
        // We have TWO choices
        string op1 = op;
        string op2 = op;
        
        op1.push_back(tolower(ip[0])); // Choice 1: Lowercase
        op2.push_back(toupper(ip[0])); // Choice 2: Uppercase
        
        ip.erase(ip.begin() + 0);      // Shrink input
        
        solve(ip, op1, v);             // Branch 1
        solve(ip, op2, v);             // Branch 2
    } 
    // 3. Otherwise, it is a digit
    else {
        // We have ONE choice
        string op1 = op;
        
        op1.push_back(ip[0]);          // Choice 1: Include as is
        
        ip.erase(ip.begin() + 0);      // Shrink input
        
        solve(ip, op1, v);             // Branch 1
    }
}
```

## Active Recall

**1. What is the fundamental difference in the recursive branching of this problem compared to the "Permutation with Case Change" problem?** 

_Answer:_ In the previous problem, every character branched into two paths because the string only contained alphabets. In this problem, the branching is conditional: alphabets branch into two paths (lowercase and uppercase), while digits branch into only one path (as they cannot change case).

**2. How do you programmatically check if a character is an alphabet (letter) in C++?**

_Answer:_ By using the built-in `isalpha()` function (e.g., `isalpha(ip[0])`).

**3. In the recursive block for processing a digit, how many new output variables (e.g., `op1`, `op2`) do you need to create, and why?** 

_Answer:_ You only need to create one output variable (e.g., `op1`). This is because digits cannot change case, so there is no decision to make; you only have one path to follow, which is appending the digit as it is.

**4. Why do we apply `tolower()` and `toupper()` directly in the recursive logic, rather than just changing 'a' to 'A'?** 

_Answer:_ Because the input string can start with either uppercase or lowercase letters (e.g., `"a1B2"`). We cannot assume the starting case. We must explicitly force one branch to be lowercase and the other to be uppercase regardless of the original character's case.
