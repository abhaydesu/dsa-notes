### 1. The Story & Problem Statement

- **The Setup:** You have 3 poles/rods: Source (`S`), Helper/Auxiliary (`H`), and Destination (`D`). There are `N` disks of different sizes stacked on the Source pole.
    
- **The Goal:** Move all `N` disks from the Source pole to the Destination pole.
    
- **The Rules (Brahma's Conditions):**
    
    1. You can only move one disk at a time.
        
    2. You cannot place a larger disk on top of a smaller disk.
        

### 2. The IBH Method Applied

Instead of overthinking how every single disk moves, we use the Induction-Base Condition-Hypothesis (IBH) method to break it down logically.

- **Step 1: Hypothesis**
    
    - Assume our function `solve(N, S, D, H)` magically knows how to move `N` disks perfectly from Source (`S`) to Destination (`D`) using the Helper (`H`).
        
    - _Therefore:_ If we call `solve(N-1, S, H, D)`, it will perfectly move the top `N-1` disks from the Source to the **Helper** pole, using the Destination pole as temporary auxiliary space.
        
- **Step 2: Induction Step (The 3-Step Process)**
    
    1. **Move N-1 disks out of the way:** Use the hypothesis to move the top `N-1` disks from `S` to `H`.
        
        - `solve(n-1, S, H, D)`
            
    2. **Move the largest disk:** Now, the largest disk (the $N^{th}$ disk) is completely free on the Source pole, and the Destination pole is empty. Move this largest disk directly from `S` to `D`.
        
        - `print("Move disk " + N + " from " + S + " to " + D)`
            
    3. **Move N-1 disks to the final spot:** Use the hypothesis again to move the `N-1` disks resting on the Helper (`H`) to their final spot on the Destination (`D`), using the Source (`S`) as the temporary auxiliary pole now.
        
        - `solve(n-1, H, D, S)`
            
- **Step 3: Base Condition**
    
    - What is the smallest valid input? `N = 1` (Only one disk).
        
    - If there is only 1 disk, you don't need any helper logic. Just move it directly from Source to Destination.
        
    - `if (n == 1) { print("Move disk 1 from " + S + " to " + D); return; }`
        

### 3. The Code Structure

C++

```
void solve(int n, int s, int d, int h) {
    // Base Condition
    if (n == 1) {
        cout << "Moving plate " << n << " from " << s << " to " << d << endl;
        return;
    }
    
    // Step 1: Move N-1 plates from Source to Helper
    solve(n-1, s, h, d);
    
    // Step 2: Move the Nth (largest) plate from Source to Destination
    cout << "Moving plate " << n << " from " << s << " to " << d << endl;
    
    // Step 3: Move N-1 plates from Helper to Destination
    solve(n-1, h, d, s);
}
```

## 🧠 Active Recall

**1. What are the two strict rules for moving disks in the Tower of Hanoi?**

_Answer:_ 1) You can only move one disk at a time. 2) A larger disk cannot be placed on top of a smaller disk.

**2. In the Hypothesis step, where do we move the top `N-1` disks initially?**

_Answer:_ We move them from the Source pole to the Helper (Auxiliary) pole, so that the largest disk on the bottom is exposed.

**3. When we call `solve(n-1, h, d, s)` at the end of the Induction step, what roles do the poles play?**

_Answer:_ We are moving the `N-1` disks _from_ the Helper pole (`h`), _to_ the final Destination pole (`d`), using the completely empty Source pole (`s`) as our temporary helper space.

**4. What is the Base Condition for this recursive function, and what does it do?**

_Answer:_ The base condition is `N == 1`. When there is only one disk left to move, it simply prints the command to move it directly from the Source to the Destination, and then returns.
