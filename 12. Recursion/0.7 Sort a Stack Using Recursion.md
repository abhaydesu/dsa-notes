### 1. The Core Strategy: Same as Sorting an Array

- If you know how to sort an array using recursion, sorting a stack is structurally the exact same problem. The logic of **Hypothesis, Induction, and Base Condition (IBH)** remains identical.
    
- The only difference is the data structure. Instead of vectors/arrays, you are dealing with a Stack.
    
- Just like the array problem, you need **two functions**:
    
    1. `sort(stack)`: Shrinks the stack, sorts the remaining stack, and calls `insert()`.
        
    2. `insert(stack, element)`: Places an element into its correct sorted position within an already sorted stack.
        

### 2. The `sort()` Function

- **Hypothesis:** `sort(stack)` will perfectly sort a stack of size N.
    
- **Induction Step:**
    
    1. Extract the top element: `temp = stack.top()`.
        
    2. Shrink the stack: `stack.pop()`.
        
    3. Call `sort(stack)` on the remaining, smaller stack.
        
    4. Call `insert(stack, temp)` to place the extracted element into the newly sorted stack.
        
- **Base Condition:** If `stack.size() == 1` or `stack.size() == 0` (empty), it is already sorted. Just `return`.
    

### 3. The `insert()` Function

- **Hypothesis:** `insert(stack, temp)` will flawlessly insert `temp` into the correct spot in a sorted stack.
    
- **Induction Step:**
    
    - If the top element of the stack is _greater_ than `temp`, you must remove the top element to look deeper into the stack.
        
    
    1. Extract the top element: `val = stack.top()`.
        
    2. Shrink the stack: `stack.pop()`.
        
    3. Recursively call `insert(stack, temp)` to put `temp` in the correct spot further down.
        
    4. Put the extracted top element back: `stack.push(val)`.
        
- **Base Condition:**
    
    - If the stack is completely empty (`stack.size() == 0`), push `temp` and `return`.
        
    - If the top of the stack is _less than or equal to_ `temp` (e.g., `stack.top() <= temp`), you have found the right spot. Push `temp` and `return`.
        

### 4. Code Syntax Changes (Vector vs. Stack)

The underlying code logic is exactly the same as the array problem, just with different syntax:

- Instead of `vector.pop_back()`, use `stack.pop()`.
    
- Instead of reading the last element with `vector[size-1]`, use `stack.top()`.
    
- Instead of `vector.push_back(val)`, use `stack.push(val)`.
    

##  Active Recall

**1. How does the logic for sorting a stack using recursion differ from sorting an array?** _Answer:_ The core logic (IBH method) and the need for two functions (`sort` and `insert`) are exactly the same. The only difference is the data structure syntax (using `top()`, `pop()`, and `push()` instead of array/vector operations).

**2. In the `sort()` function, what do you do with the top element before making the recursive call?** 
_Answer:_ You must save the top element in a temporary variable (e.g., `temp = stack.top()`) and then remove it from the stack (`stack.pop()`) before recursively calling `sort()`.

**3. In the `insert()` function, what is the Base Condition that indicates you have found the correct spot to insert the element?**
_Answer:_ If the stack is empty OR if the element at the top of the stack is less than or equal to the element you are trying to insert.

**4. If the top element of the stack is greater than the element you are trying to insert, what are the steps in your Induction phase?**
_Answer:_ Store the top element in a variable, pop it off the stack, recursively call `insert()` with your target element, and finally push the stored top element back onto the stack once the recursive call finishes.
