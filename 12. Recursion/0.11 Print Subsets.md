### 1. Problem Statement

- **Goal:** Given a string (e.g., `"ab"`), print all possible subsets (or subsequences).
    
- **Input:** String `"ab"`
    
- **Output:** `" " (empty)`, `"a"`, `"b"`, `"ab"`
    
- **The Approach:** This problem is best solved by drawing out the **Recursive Tree** using the **Input-Output Method**.

### 2. Designing the Recursive Tree (The Core Logic)

In recursion, we focus on making _decisions_. For every character in the input string, we have exactly two choices:

1. **Do not include** the character in our subset.
    
2. **Include** the character in our subset.
    

**The Flow (Example with Input = "ab", Output = ""):**

- At the root, `Input = "ab"`, `Output = ""`
    
- We look at the first character: `'a'`. We make two branches:
    
    - **Branch 1 (Exclude 'a'):** Output remains `""`. We remove `'a'` from the input. New `Input = "b"`.
        
    - **Branch 2 (Include 'a'):** Output becomes `"a"`. We remove `'a'` from the input. New `Input = "b"`.
        
- We repeat this process for the next character (`'b'`) on _both_ branches until the `Input` string becomes completely empty.
    

### 3. Translating the Tree to Code

Once the tree is drawn, writing the code is just mimicking the tree's behavior.

- **Step 1: The Initial Setup (Main Function)**
    
    - Initialize `string ip = "ab";`
        
    - Initialize `string op = "";`
        
    - Call the recursive function: `solve(ip, op);`
        
- **Step 2: The Base Condition (Leaf Nodes)**
    
    - Look at the recursive tree: When do we get our final answers? When the `Input` string becomes completely empty.
        
    - _Code:_ `if (ip.length() == 0) { cout << op << endl; return; }`
        
- **Step 3: Creating the Choices (Induction/Tree Logic)**
    
    - Create two new output strings to represent the two decisions. Both initially inherit the current output string.
        
        - `string op1 = op;` (Represents the choice to NOT include the character)
            
        - `string op2 = op;` (Represents the choice to INCLUDE the character)
            
    - Actually execute the "Include" choice for `op2` by pushing the first character of the input into it.
        
        - `op2.push_back(ip[0]);`
            
- **Step 4: Shrinking the Input & Making Recursive Calls**
    
    - Since we have processed the first character of the input (index 0), we must remove it from the input string so it isn't processed again.
        
        - `ip.erase(ip.begin() + 0);`
            
    - Finally, make two recursive calls representing the two branches of the tree.
        
        - `solve(ip, op1);` (Branch 1: Excluded)
            
        - `solve(ip, op2);` (Branch 2: Included)
            

## Active Recall

**1. For every character in the input string, what are the two choices you must make when building the recursive tree?** _Answer:_ The two choices are whether to **include** the character in the current output subset, or to **exclude** (not include) the character from the current output subset.

**2. How do you identify the Base Condition by looking at the Input-Output Recursive Tree?** _Answer:_ By looking at the leaf nodes (the very bottom) of the tree. You will notice that at every leaf node where a final subset is formed, the Input string has become completely empty (its length is 0).

**3. In the code implementation, before you make the two recursive calls for the left and right branches, what MUST you do to the `ip` (input) string?** _Answer:_ You must remove the first character of the input string (`ip.erase(ip.begin() + 0)`) because you have just finished making a decision about it, and you need the input to be smaller for the next recursive step.

**4. Why do we create two separate variables (`op1` and `op2`) in the recursive function?** _Answer:_ Because `op1` represents the state of the output string if we choose _not_ to include the current character, and `op2` represents the state of the output string if we _do_ choose to include the current character. We need to pass these two distinct states to the two subsequent recursive calls.
