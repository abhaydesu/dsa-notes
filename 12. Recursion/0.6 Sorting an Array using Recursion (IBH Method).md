### 1. The Strategy: Two Recursive Functions

- Sorting an array using pure recursion (without typical algorithms like Merge Sort or Quick Sort) might seem tricky.
    
- We use the **IBH (Induction, Base Condition, Hypothesis)** method.
    
- To achieve this, we actually need **two separate recursive functions**:
    
    1. **`sort()`**: This function shrinks the array, sorts the smaller array, and then passes the sorted array and the removed element to the `insert()` function.
        
    2. **`insert()`**: This function takes a _sorted_ array and a single element, and recursively finds the correct position to place that element while keeping the array sorted.
        

### 2. The `sort()` Function

- **Hypothesis:** Assume `sort(arr)` will perfectly sort an array of size N. Therefore, `sort(arr)` called on an array of size N-1 will perfectly sort that smaller array.
    
- **Induction Step:**
    
    1. Extract and store the last element of the array.
        
    2. Reduce the size of the array by 1 (e.g., using `pop_back()`).
        
    3. Call `sort(arr)` on this smaller array. (Now you have a sorted smaller array).
        
    4. Call the helper function `insert(arr, element)` to put the stored element into its correct sorted position in the newly sorted array.
        
- **Base Condition:** The smallest valid input is an array of size 1 or 0. If the array size is `1` or `0`, it is already sorted. Just `return`.
    

### 3. The `insert()` Function

- **Hypothesis:** Assume `insert(arr, temp)` perfectly inserts the element `temp` into the correct spot in a sorted array of size N. Therefore, it will also work perfectly for a sorted array of size N-1.
    
- **Induction Step:**
    
    - If the element `temp` is smaller than the last element of the array, you cannot just push it to the back.
        
    
    1. Extract and store the last element of the array.
        
    2. Reduce the array size by 1 (`pop_back()`).
        
    3. Recursively call `insert(arr, temp)` on this smaller array.
        
    4. Once `temp` has been inserted into the smaller array, push the originally stored last element back onto the array (`push_back()`).
        
- **Base Condition:**
    
    - If the array is completely empty (`size == 0`), simply push `temp` into the array and `return`.
        
    - If the last element of the current array is _less than or equal to_ `temp`, you have found the correct spot! Just push `temp` to the back of the array and `return`.
        

## Active Recall

**1. Why do we need two separate recursive functions to sort an array using the IBH method?** _Answer:_ The `sort()` function is responsible for breaking down the array and sorting the smaller sub-problems. The `insert()` function is required as the induction step for `sort()`—its specific job is to take a single element and accurately place it into an already sorted array.

**2. In the `sort()` function, what is the Base Condition that stops the recursion?** _Answer:_ If the array's size is 1 or 0, it is considered already sorted, so the function simply returns.

**3. In the `insert()` function, before we recursively call `insert()` on a smaller array, what must we do with the last element of the current array?** _Answer:_ We must save the last element in a variable and remove it from the array (e.g., `pop_back()`). After the recursive `insert()` call finishes, we must put this saved element back into the array (e.g., `push_back()`).

**4. What are the two Base Conditions inside the `insert()` function where the recursion stops and the element is finally inserted?** _Answer:_ The recursion stops if the array becomes empty (size == 0), or if the element we are trying to insert is greater than or equal to the current last element of the array. In either case, we push the element to the back of the array and return.
