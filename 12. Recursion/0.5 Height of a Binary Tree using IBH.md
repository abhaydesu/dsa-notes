### 1. The Power of IBH on Trees

- The IBH (Induction, Base Condition, Hypothesis) method is not just for arrays and linear structures; it works exceptionally well on Tree data structures.
    
- This problem is a classic example of how beautifully the IBH method maps to Tree logic without needing to visualize the entire recursive tree in your head.
    

### 2. Solving with the 3 Steps of IBH

We need to find the maximum height (or depth) of a given Binary Tree starting from the root node.

- **Step 1: Hypothesis (Design the Function)**
    
    - _Design:_ Assume a function `height(node)` takes a node and correctly returns the integer height of the tree starting from that node.
        
    - _Logical conclusion:_ Therefore, if you call `height(root.left)`, it will correctly return the height of the left subtree. If you call `height(root.right)`, it will correctly return the height of the right subtree.
        
- **Step 2: Induction Step (Make it Work)**
    
    - _What you have:_ You now have two values: `left_height` (let's say it's 3) and `right_height` (let's say it's 2).
        
    - _The Logic:_ The height of the entire tree from the root is dictated by its longest branch. Just like a person standing on stilts of unequal lengths, the total height is determined by the longer stilt.
        
    - _Code logic:_ Take the maximum of the left and right heights. Then, add `1` to account for the current root node itself.
        
    - `return 1 + max(left_height, right_height)`
        
- **Step 3: Base Condition (Stop the Magic)**
    
    - _Smallest Valid Input:_ Think about shrinking the tree. A tree with 3 nodes shrinks to 1 node, which shrinks to... no nodes.
        
    - _The Stopping Point:_ The smallest valid (or invalid) input for a tree node is when it is `NULL` (it points to nothing).
        
    - _Code logic:_ If a node is `NULL`, its height is `0`.
        
    - `if (root == NULL) return 0;`
        

### 3. The Final Code Structure

```cpp
int height(Node* root) {
    // Base Condition
    if (root == NULL) 
        return 0;
        
    // Hypothesis (applied to smaller inputs)
    int left_height = height(root->left);
    int right_height = height(root->right);
    
    // Induction
    return 1 + max(left_height, right_height);
}
```

## Active Recall

**1. When designing the Hypothesis for the height of a binary tree, what do you assume the recursive calls to `root.left` and `root.right` will return?** _Answer:_ You assume they will flawlessly return the correct height of the entire left subtree and the entire right subtree, respectively.

**2. In the Induction step, why do we use the `max()` function between the left and right heights?** _Answer:_ Because the total height of a tree is determined by its longest continuous branch from the root to a leaf. The shorter branch does not dictate the maximum depth.

**3. Why do we add `1` to the maximum of the left and right heights in the Induction step?** _Answer:_ The recursive calls return the heights of the subtrees. You must add `1` to account for the current root node that connects them.

**4. What is the Base Condition for this tree problem, and what value does it return?** _Answer:_ The base condition is when the current node is `NULL` (meaning it doesn't exist). In this case, the height of a non-existent tree is `0`, so it returns `0`.
