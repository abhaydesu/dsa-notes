### 1. Problem Statement

- **Input:** You are given two integers, `N` (row number) and `K` (column/index number). Both are 1-indexed.
    
- **The Grammar Rules:**
    
    - Row 1 is always `0`.
        
    - For every subsequent row, you look at the previous row.
        
    - Replace every `0` with `01`.
        
    - Replace every `1` with `10`.
        
- **Goal:** Find and return the character (either `0` or `1`) present at the `K`th position in the `N`th row.
    

_Example Grammar Generation:_

- N=1: `0`
    
- N=2: `01`
    
- N=3: `0110`
    
- N=4: `01101001`
    

### 2. Key Observations (The Trick)

To solve this recursively, you don't need to generate the actual strings (which would cause memory/time limit errors). Instead, observe the pattern between an `N`th row and the `(N-1)`th row:

1. **Length:** Every row is exactly twice the length of the previous row. Length of row `N` is $2^{N-1}$. Therefore, the `mid` point is $2^{N-2}$.
    
2. **The First Half (Left Side):** The first half of row `N` is an _exact identical copy_ of the entirety of row `N-1`.
    
3. **The Second Half (Right Side):** The second half of row `N` is the _exact complement_ (opposite) of the entirety of row `N-1`. (i.e., `0` becomes `1`, and `1` becomes `0`).
    

### 3. The Logic using IBH Method

- **Base Condition:**
    
    - The simplest valid input given by the problem is `N = 1` and `K = 1`.
        
    - If `N == 1` and `K == 1`, return `0`.
        
- **Hypothesis & Induction:**
    
    - Calculate the `mid` point of the current row `N`. `mid = pow(2, N-1) / 2`.
        
    - **Case 1: K lies in the First Half (`K <= mid`)**
        
        - Since the first half is identical to the previous row, the answer is exactly the same as asking for the `K`th element in row `N-1`.
            
        - _Action:_ `return solve(N-1, K)`
            
    - **Case 2: K lies in the Second Half (`K > mid`)**
        
        - Since the second half is the complement of the previous row, we need to map `K` back to the previous row. The index `K` in the second half corresponds to index `K - mid` in the previous row.
            
        - _Action:_ Find the answer for `K - mid` in row `N-1`, and return its complement (using `!` or logical NOT).
            
        - _Action:_ `return !solve(N-1, K - mid)`
            

### 4. Code Structure

```cpp
int solve(int n, int k) {
    // Base Condition
    if (n == 1 && k == 1) return 0;
    
    // Calculate mid
    int mid = pow(2, n - 1) / 2;
    
    // Hypothesis & Induction
    if (k <= mid) {
        return solve(n - 1, k);
    } else {
        return !solve(n - 1, k - mid);
    }
}
```

## Active Recall

**1. What are the specific replacement rules to generate the next row in this grammar?**

_Answer:_ Every `0` in the current row is replaced by `01` in the next row, and every `1` in the current row is replaced by `10` in the next row.

**2. How does the first half of row N relate to row N-1?**

_Answer:_ The first half of row N is an exact, identical copy of the entirety of row N-1.

**3. How does the second half of row N relate to row N-1?**

_Answer:_ The second half of row N is the exact complement (inverted values, where 0 becomes 1 and 1 becomes 0) of the entirety of row N-1.

**4. If K is in the second half of the row (K > mid), how do you calculate its corresponding mapped index in the previous row?**

_Answer:_ You map it back by subtracting `mid` from `K`. The recursive call uses the index `K - mid`.
