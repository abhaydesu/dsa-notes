### 1. Problem Statement

- **Goal:** Reverse a given stack using _only_ recursion.
    
- **Constraint:** You cannot use an extra stack, arrays, or any extra space directly (the recursion call stack will handle the memory).
    
- **Input:** Stack `[1, 2, 3, 4, 5]` (where 5 is the top element).
    
- **Output:** Stack `[5, 4, 3, 2, 1]` (where 1 is the new top element).
    

### 2. The Strategy (Two Recursive Functions)

Similar to sorting a stack, reversing a stack requires two distinct recursive functions:

1. **`reverse()`**: The main function that breaks down the stack.
    
2. **`insert()`**: A helper function that takes an element and inserts it at the very _bottom_ of an existing stack.
    

### 3. The Main Function: `reverse()`

- **Hypothesis:** Assume `reverse(stack)` perfectly reverses a stack of size `N`. Therefore, calling it on a stack of size `N-1` will perfectly reverse that smaller stack.
    
- **Induction Step:**
    
    1. Extract the top element: `temp = stack.top()` (e.g., store 5).
        
    2. Pop it off the stack: `stack.pop()`.
        
    3. Call `reverse(stack)` on the remaining items. (Now, `[1,2,3,4]` becomes `[4,3,2,1]`).
        
    4. Now you have a reversed stack, but your `temp` element (5) needs to go at the _very bottom_ to complete the overall reversal. Call the helper function: `insert(stack, temp)`.
        
- **Base Condition:**
    
    - If `stack.size() == 1` or `stack.size() == 0` (empty), a single-element (or empty) stack is already reversed! Just `return`.
        

### 4. The Helper Function: `insert()`

- **Goal:** Insert a given element exactly at the bottom of the stack.
    
- **Hypothesis:** Assume `insert(stack, element)` successfully places the element at the bottom of a stack of size N.
    
- **Induction Step:**
    
    - Since you can only push to the top of a stack, you must temporarily move all current items out of the way to reach the bottom.
        
    
    1. Extract the current top element: `val = stack.top()`.
        
    2. Pop it: `stack.pop()`.
        
    3. Recursively call `insert(stack, element)` to keep digging down.
        
    4. Once the original element is successfully placed at the bottom, put the temporarily removed items back on top: `stack.push(val)`.
        
- **Base Condition:**
    
    - When do you reach the "bottom"? When the stack is completely empty.
        
    - If `stack.size() == 0`, simply push the target element onto the stack: `stack.push(element)` and `return`.
        

## Active Recall

**1. Why is a secondary/helper recursive function required to reverse a stack?** _Answer:_ The main recursive function (`reverse`) breaks the stack down and reverses the remaining elements. However, the element that was originally at the top now needs to be placed at the very bottom. Because standard stack operations only allow insertion at the top, a helper function (`insert`) is needed to recursively empty the stack, place the element at the bottom, and then put everything back.

**2. In the main `reverse()` function, what is the Base Condition that stops the recursion?** _Answer:_ If the stack's size is 1 or 0, it means the stack is technically already reversed (a single element is its own reverse), so the function simply returns.

**3. What is the Base Condition for the helper `insert()` function?** _Answer:_ The base condition is `stack.size() == 0` (an empty stack). This signifies that you have successfully reached the "bottom" of the stack, and you can now push the target element.

**4. Describe the exact Induction step inside the helper `insert()` function.** _Answer:_ You store the current top element in a variable (`val = stack.top()`), pop it off (`stack.pop()`), call the `insert()` function recursively with the target element, and finally push the stored `val` back onto the stack (`stack.push(val)`) once the recursive call is completed.
