### 1. Handling Duplicate Subsets (Print Unique Subsets)

- **The Problem:** When the input string contains duplicate characters (e.g., `"aab"`), the standard subset generation logic will produce duplicate subsets in the output (e.g., it will generate `"a"`, `"a"`, `"ab"`, `"ab"`, etc.).
    
- **The Solution:** Instead of immediately printing the subsets at the leaf nodes (Base Condition), store them in a data structure that tracks uniqueness.
    
- **Implementation Steps:**
    
    1. Create a `set<string>` or an `unordered_map<string, int>` globally (or pass by reference).
        
    2. At the base condition (`if input.length() == 0`), insert the output string into the `set` (or map).
        
    3. Because Sets inherently reject duplicate values, they will automatically filter out any repeated subsets.
        
    4. After the recursive function finishes entirely, iterate through the `set` and print the unique subsets.
        

### 2. Understanding the Terminology (Crucial for Interviews)

Interviewers use different terms that essentially ask for the exact same recursive logic. It is vital to know the differences and similarities.

- **Subsequence:** A sequence derived by deleting some or no elements of a string **without changing the order** of the remaining elements. (e.g., For `"abc"`, `"ac"` is valid, but `"ca"` is invalid).
    
- **Subset:** A mathematical term describing a collection of elements. Order _technically_ does not matter (i.e., set `{a, c}` is the same as `{c, a}`).
    
- **Power Set:** The set of _all possible subsets_ of a given set. (The power set of `{a,b}` is `{ {}, {a}, {b}, {a,b} }`).
    
- **The Big Takeaway:** If an interviewer asks you to print **"All Subsets," "Power Set," or "All Subsequences,"** you will write the **exact same code**.
    
    - _Why?_ Because generating elements by maintaining the original order (which is what our recursive tree does) safely satisfies the strict rules of a Subsequence, while naturally producing valid Subsets and Power Sets. (The testing platforms will expect the output printed in the original string's relative order).
        

### 3. Output Formatting Variations (Lexicographical Order)

- **The Problem:** The standard recursive tree generates subsets in a specific order based on the left/right branching. Sometimes, a platform requires the output to be in **Lexicographical (dictionary/alphabetical) order**.
    
- **The Solution:** Do not try to alter the recursive tree logic to force an alphabetical output.
    
    - Instead of printing, store all the subsets in a `vector<string>`.
        
    - After the recursion is fully complete, use the standard `sort(vector.begin(), vector.end())` function.
        
    - Print the sorted vector.
        

## Active Recall

**1. If the input string is `"aba"`, why will the standard subset recursive tree produce duplicate outputs?**

_Answer:_ Because there are two identical `'a'` characters in different positions. Making the choice to include the first `'a'` but exclude the second `'a'` yields the exact same output string as excluding the first `'a'` but including the second `'a'`.

**2. What data structure is best used to automatically filter out duplicate subsets generated by the recursive tree?** 

_Answer:_ A `set` (or `unordered_set` / `map`). By inserting the output strings into a set at the base condition, duplicates are automatically ignored.

**3. What is the fundamental difference between a Subsequence and a Subset in pure theory?** 

_Answer:_ In a Subsequence, the relative order of the elements from the original string must be strictly maintained. In a Subset (mathematically), the order of elements does not matter.

**4. Why do we write the exact same code for printing Subsequences, Subsets, and Power Sets in coding interviews?**

_Answer:_ Because generating elements while maintaining the original order (our standard logic) satisfies the strict requirements of a Subsequence, and inherently produces all valid subsets required for a Power Set. Coding platforms expect this ordered output regardless of which term they use in the problem description.

**5. How do you handle a requirement to print the subsets in lexicographical (dictionary) order?**

_Answer:_ Store all the generated subsets in a vector or array during the base condition, and then simply sort that vector alphabetically after the recursion is finished before printing.
