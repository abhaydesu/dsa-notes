### 1. Problem Statement

- **Input:** An integer `N` representing the number of pairs of parentheses.
    
- **Goal:** Generate all possible well-formed (balanced) combinations of parentheses and return them in a list/vector.
    
- **Output for N = 3:**
    
    - `"((()))"`
        
    - `"(()())"`
        
    - `"(())()"`
        
    - `"()(())"`
        
    - `"()()()"`
        
- **Understanding `N`:** If `N = 3`, you have exactly 3 Open brackets `(` and exactly 3 Close brackets `)` to use. Total length of each string will be `2 * N` (6 boxes to fill).
    

### 2. Identifying Choices and Constraints (The Core Logic)

Because we have a set number of Open and Close brackets to place in specific sequences, this is a decision-making problem (Recursion). Instead of passing a string as the input, our "input state" is represented by two integer counters: **`open`** and **`close`**. Both start at `N`.

At any given point, you have a maximum of **two choices**:

1. **Choice 1: Place an Open Bracket `(`**
    
    - _Constraint:_ You can _always_ place an open bracket as long as you have open brackets left to use.
        
    - _Condition:_ `if (open > 0)`
        
2. **Choice 2: Place a Close Bracket `)`**
    
    - _Constraint:_ You CANNOT just place a close bracket anytime. If you place a close bracket when there is no unmatched open bracket before it (e.g., starting a string with `)`), it becomes unbalanced immediately.
        
    - _Condition:_ You can only use a close bracket if you have strictly more close brackets left unused than open brackets.
        
    - `if (close > open)`
        

### 3. Designing the Recursive Tree (Input-Output Method)

- **Initial Setup:** `open = N`, `close = N`, `Output = ""`
    
- **Branching:**
    
    - At the root (`open = 3`, `close = 3`, `Output = ""`), `open > 0` is true, but `close > open` is false. So, we only have one branch: placing an open bracket.
        
    - New state: `open = 2`, `close = 3`, `Output = "("`.
        
    - From here, `open > 0` is true (Branch 1) AND `close > open` is true because 3 > 2 (Branch 2).
        
- **Base Condition:**
    
    - When you have exhausted all your brackets, meaning both `open == 0` and `close == 0`, you have successfully formed a balanced string. Add the `Output` string to your result vector and return.
        

### 4. Code Structure Breakdown


```cpp
void solve(int open, int close, string op, vector<string>& v) {
    // 1. Base Condition
    if (open == 0 && close == 0) {
        v.push_back(op);
        return;
    }
    
    // 2. Choice 1: Place an Open Bracket
    if (open > 0) {
        string op1 = op;
        op1.push_back('(');
        // Make the recursive call with one less open bracket available
        solve(open - 1, close, op1, v);
    }
    
    // 3. Choice 2: Place a Close Bracket
    // Note: This is an independent 'if', NOT an 'else if'
    if (close > open) {
        string op2 = op;
        op2.push_back(')');
        // Make the recursive call with one less close bracket available
        solve(open, close - 1, op2, v);
    }
}
```

## Active Recall

**1. Instead of passing an input string to shrink, what variables represent our "input state" in this problem?**

_Answer:_ Two integer counters, `open` and `close`, which represent the remaining number of available open brackets `(` and close brackets `)` respectively.

**2. Under what exact condition are you allowed to make the recursive choice to add an Open bracket `(`?**

_Answer:_ You are allowed to add an open bracket as long as you still have open brackets left in your inventory (i.e., `open > 0`).

**3. Under what exact condition are you allowed to make the recursive choice to add a Close bracket `)`?**

_Answer:_ You can only add a close bracket if the count of available close brackets is strictly greater than the count of available open brackets (`close > open`). This ensures that there is always an unmatched open bracket preceding it, preventing invalid strings like `")("`.

**4. What is the Base Condition for this recursive function, indicating that a valid string is complete?**

_Answer:_ When both `open == 0` and `close == 0`, meaning you have successfully used exactly `N` open brackets and `N` close brackets.
