### 1. Problem Statement

- **Context:** N people are standing in a circle. A sword is handed to the first person, and they kill the kth person next to them in the circle. The sword is then passed to the very next living person, and the process repeats until only one person is left alive.
    
- **Input:** Two integers, `n` (total number of people) and `k` (the counting step to decide who dies next).
    
- **Output:** The position of the last surviving person.
    

### 2. The Strategy: Arrays and Recursion

Instead of relying on complex mathematical formulas, we can simulate the circle and solve this using the IBH (Induction, Base Condition, Hypothesis) recursive method.

- **Data Representation:** Create a vector or array filled with numbers from 1 to `n`. This represents the living people.
    
- **The Circular Logic:** Because people are in a circle, counting will eventually go past the end of the array and need to restart from the beginning. We handle this wrap-around effect using the modulo operator (`%`).
    

### 3. The IBH Method Steps

- **Initial Setup (Before Recursion):**
    
    - Create the vector `[1, 2, 3 ... n]`.
        
    - Since arrays are 0-indexed, the starting index (where the sword begins) is `0`.
        
- **Step 1: Hypothesis & Induction (The Core Logic)**
    
    - To find the exact index of the person who will be killed, use this formula: `kill_index = (current_index + k - 1) % vector.size()`.
        
    - _Why k-1?_ Because the person holding the sword counts as step 1.
        
    - Once the index is calculated, remove that person from the vector (using the `erase()` function).
        
    - Recursively call the function with the newly shrunk vector. The `current_index` passed to the next function call will be the exact same `kill_index` you just calculated. (When a person is erased from an array, the next person automatically shifts into that exact index, simulating the passing of the sword).
        
    - _Note:_ Unlike other recursive problems, there is no extra work required in the induction step. You just return whatever the recursive call gives you.
        
- **Step 2: Base Condition (When to stop)**
    
    - The game ends when only one person is left.
        
    - Code Logic: `if (vector.size() == 1)`.
        
    - Action: Return the only remaining element, which is `vector[0]`.
        

## Active Recall

**1. What data structure is used to easily simulate the people standing in the circle?** _Answer:_ An array or a vector containing integers from 1 to `n`.

**2. Why must we use the modulo operator (%) when calculating the index of the person to be killed?** _Answer:_ Because the counting happens in a circle. If the count exceeds the number of people currently at the end of the array, the modulo operator ensures the count seamlessly wraps around to the beginning of the array.

**3. In a 0-indexed array, what is the exact formula to calculate the index of the next person to be killed?** _Answer:_ `(current_index + k - 1) % current_array_size`.

**4. What is the Base Condition that halts the recursive execution?** _Answer:_ The recursion stops when the size of the vector becomes exactly 1. At this point, the single remaining element is the survivor and is returned as the answer.

**5. Why is there no extra code written in the Induction step after the recursive call returns?** _Answer:_ Because the problem relies entirely on shrinking the input until the base condition is met. Once the base condition returns the surviving person, that value is the absolute final answer and simply needs to be passed back up the recursive chain without any modifications.
